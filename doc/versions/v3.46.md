# Version 3.46 - Expand List Item Penjualan di Daftar Penjualan (Expandable Sales Items List)

## 1. Masalah / Peluang
* **Konteks:** Pemilik toko memerlukan cara cepat untuk melihat daftar item produk yang dibeli dalam suatu transaksi penjualan langsung dari halaman daftar penjualan (`PenjualanListView`), tanpa harus membuka lembar detail (`EditPenjualanSheet`) untuk setiap transaksi. Hal ini penting untuk pemindaian daftar secara cepat dan efisien.
* **Objektif:** Menambahkan fitur "expand down" (accordion / disclosure group) pada setiap baris item penjualan di `PenjualanListView`. Ketika diekspansi, daftar produk yang dibeli beserta kuantitas, harga, dan diskonnya akan ditampilkan secara kompak di bawah informasi utama baris tersebut.
* **Constraint:** Pengguna harus tetap dapat mengklik baris penjualan tersebut untuk membuka lembar detail transaksi (`EditPenjualanSheet`).

## 2. Alur Pengguna & Spesifikasi UX

### A. Tampilan Baris Penjualan Ter-kolaps (Collapsed State)
1. Setiap baris penjualan memiliki tombol chevron (segitiga kecil atau arah kanan `chevron.right`) di sebelah kiri kode invoice (`invoiceNo`).
2. Tapping tombol chevron tersebut akan mengekspansi baris ke bawah dengan animasi halus, mengubah chevron menjadi mengarah ke bawah (`chevron.right` berputar 90 derajat).
3. Tapping area di luar tombol chevron (nama pelanggan, metode bayar, total nominal, chevron kanan navigasi detail) tetap akan membuka lembar detail penjualan (`EditPenjualanSheet`).

### B. Tampilan Baris Penjualan Ter-ekspansi (Expanded State)
1. Di bawah informasi utama penjualan, terdapat garis pembatas horizontal tipis (`Divider`).
2. Di bawah pembatas tersebut, daftar produk (`order.items`) ditampilkan secara kompak dengan indentasi kiri agar selaras dengan detail teks di atasnya.
3. Setiap item menampilkan:
   * Nama produk & ukuran (Format: `[Nama Produk] · [Ukuran]`, misal: `Scrunchie Satin · M`).
   * Kuantitas & harga satuan (Format: `[Qty] pcs × [Harga]`, misal: `2 pcs × Rp15.000`).
   * Informasi diskon jika ada (Format: `- [Diskon]`, dengan teks berwarna merah).
   * Total nominal item di sebelah kanan (Format: `[Total Harga]`, misal: `Rp30.000`).
4. Baris tersebut tetap dapat dikolaps kembali dengan mengetuk tombol chevron di kiri atas.

---

## 3. Spesifikasi API & Perubahan Model

* Data item transaksi penjualan sudah dimuat secara lengkap (termasuk produk, ukuran, kuantitas, harga, diskon, dll.) ketika mengambil daftar penjualan melalui `api.getSalesOrders`.
* Oleh karena itu, **tidak ada perubahan API atau model data baru yang diperlukan**. Seluruh pekerjaan murni dilakukan pada lapisan UI di frontend iOS.

## 4. Rincian Implementasi Kode Frontend

### A. `PenjualanListView.swift` (State Manajemen Ekspansi)
* Tambahkan state properti baru untuk menyimpan ID penjualan yang sedang diekspansi:
  ```swift
  @State private var expandedOrderIds: Set<UUID> = []
  ```

### B. `PenjualanListView.swift` (Komponen `OrderRow` Refactoring)
* Ubah parameter inisialisasi `OrderRow` agar menerima properti ekspansi dan closure interaksi:
  ```swift
  private struct OrderRow: View {
      let order: SalesOrder
      let isExpanded: Bool
      let onToggleExpand: () -> Void
      let onTapRow: () -> Void
  ```
* Bungkus struktur tampilan utama ke dalam `VStack` yang berisi:
  1. `HStack` utama dengan tombol expand di kiri dan konten baris di kanan (sebagai `Button` independen menggunakan `.buttonStyle(.borderless)`).
  2. Kondisi `if isExpanded` untuk merender daftar item kompak dengan format estetik yang selaras dengan `OuraTheme`.
