## Latar Belakang

Produk yang tidak melewati alur Optimasi Pola → Batch Produksi → Konfirmasi tidak memiliki HPP. Akibatnya Price Advisor tidak bisa digunakan dan margin tidak bisa dihitung di Laporan.

v3.19 menambahkan jalur pendek: user bisa input HPP per komponen secara manual saat pertama kali scan QR untuk tambah stok, langsung dari `ScanToStockSheet`. HPP ini tersimpan di `product_sizes` dan dipakai sebagai fallback di seluruh app (Price Advisor, Laporan, dsb.) sampai ada konfirmasi batch yang menggantikannya.

## A. ScanToStockSheet — Enhanced (Dari Produksi)

### Behavior

Saat alasan = **"Dari Produksi"** dan produk belum memiliki HPP (batch maupun manual):

1. Sheet menampilkan **nudge informatif** di bawah qty:
   > `⚠ HPP belum ada — Price Advisor tidak aktif. Atur sekarang?`
   > `[Atur HPP ▼]` — collapsible, default collapsed

2. Jika user tap **"Atur HPP"** → section HPP expand dengan 5 `CurrencyInputField`:
   - Kain (fabric)
   - Bahan Pooled
   - Hardware
   - Tenaga Kerja
   - Overhead
   - **HPP Total** — auto-sum real-time, read-only
   - **Price Advisor** expandable (identik dengan di ProduksiBatchView, pure client-side math)
   - "Gunakan Harga Ini" → set `editSellingPrice` sehingga tersimpan bersama save

3. Jika user **abaikan** nudge → simpan seperti biasa tanpa HPP (behavior existing)

4. Jika produk sudah memiliki HPP (batch atau manual) → tampilkan HPP read-only + Price Advisor langsung tanpa nudge

### Material Deduction (Toggle)

Jika ada `PatternSpec` aktif untuk varian ini:
- Tampilkan toggle **"Kurangi bahan otomatis"** — default **ON**
- Di bawah toggle: preview material yang akan dikurangi, mis. `Satin Merah −135 cm (3 pcs × 45 cm)`
- Simpan → call `addStockFromBahan` (pakai spec) bukan `adjustStock`

Jika tidak ada PatternSpec → toggle tidak muncul, simpan pakai `adjustStock` seperti sekarang.

### Data yang Disimpan Saat Save

| Data | Kondisi | API |
|---|---|---|
| Stock ledger (+qty) | Selalu | `POST /stock-adjust` atau `addStockFromBahan` |
| `manual_hpp_*` di product_sizes | Hanya jika HPP section diisi (> 0) | `PATCH /products/:sku/sizes/:id` |
| `selling_price` | Hanya jika "Gunakan Harga Ini" di-tap | `PATCH /products/:sku/sizes/:id` |

Save dilakukan sequentially: stock dulu, lalu PATCH HPP (jika ada). Jika PATCH HPP gagal, stock tetap tersimpan — HPP bisa diisi ulang dari `ProdukSizeDetailView`.

### States

```swift
// Tambahan di ScanToStockSheet
@State private var showHppSection: Bool = false
@State private var editHppFabric: Double? = nil
@State private var editHppPooled: Double? = nil
@State private var editHppHardware: Double? = nil
@State private var editHppLabor: Double? = nil
@State private var editHppOverhead: Double? = nil
@State private var editSellingPrice: Double? = nil
@State private var deductBahan: Bool = true   // default ON jika ada spec
@State private var relatedSpec: PatternSpec? = nil

private var editHppTotal: Double {
    (editHppFabric ?? 0) + (editHppPooled ?? 0) + (editHppHardware ?? 0)
    + (editHppLabor ?? 0) + (editHppOverhead ?? 0)
}
private var hasManualHpp: Bool { editHppTotal > 0 }
```

## B. ProdukSizeDetailView — HPP Manual Override

### Behavior

Saat `size.latestHppBreakdown == nil` (tidak ada batch HPP):

**Read mode:**
- Jika ada `manualHppBreakdown`: tampilkan HPP card identik dengan batch HPP card, dengan label header `RINCIAN HPP · MANUAL` + chip kecil `[manual]` (warning color)
- Jika tidak ada HPP sama sekali: tampilkan placeholder "HPP belum ada — set manual di bawah"
- Price Advisor: selalu tampil. Jika ada manual HPP → aktif langsung. Jika tidak ada → tampilkan pesan ringan "Isi HPP manual di bawah untuk menggunakan Price Advisor"

**Edit mode:**
- Jika tidak ada batch HPP: tampilkan 5 `CurrencyInputField` untuk komponen HPP manual
- Jika ada batch HPP: tidak tampilkan field HPP (batch lebih akurat, tidak di-override dari sini)
- `PriceAdvisorSection` (shared component, extracted dari ProduksiBatchView) langsung di bawah HPP — aktif saat total > 0
- "Gunakan Harga Ini" set `editSellingPrice` dan di-save bersama dalam satu PATCH

### Shared Component: PriceAdvisorSection

`PriceAdvisorSection` di `ProduksiBatchView.swift` saat ini `private struct` — perlu diubah menjadi `struct` internal dan dipindahkan ke `Components/PriceAdvisorSection.swift`.

Signature tetap:
```swift
struct PriceAdvisorSection: View {
    let hpp: HPPBreakdown
    let itemLabel: String
    let onApply: (Double) -> Void
}
```

## D. ProductSizeDetail — Extended

```swift
struct ProductSizeDetail: Decodable, Identifiable {
    // ... existing fields ...

    // NEW — dari backend:
    var manualHppFabric: Double?
    var manualHppPooled: Double?
    var manualHppHardware: Double?
    var manualHppLabor: Double?
    var manualHppOverhead: Double?

    // Computed:
    var manualHppBreakdown: HPPBreakdown? {
        let total = (manualHppFabric ?? 0) + (manualHppPooled ?? 0)
                  + (manualHppHardware ?? 0) + (manualHppLabor ?? 0)
                  + (manualHppOverhead ?? 0)
        guard total > 0 else { return nil }
        return HPPBreakdown(
            fabric: manualHppFabric ?? 0,
            pooledMaterial: manualHppPooled ?? 0,
            hardware: manualHppHardware ?? 0,
            labor: manualHppLabor ?? 0,
            overhead: manualHppOverhead ?? 0,
            total: total
        )
    }

    // Effective HPP untuk Price Advisor — batch first, manual fallback:
    var effectiveHppBreakdown: HPPBreakdown? {
        latestHppBreakdown ?? manualHppBreakdown
    }
}
```

## UX Flow: ScanToStockSheet

```
Scan QR → identifikasi size
     │
     ▼
ScanToStockSheet terbuka
     │
     ├── [Alasan = "Dari Produksi"] ─────────────────────────────────┐
     │    │                                                           │
     │    ├── Punya HPP (batch/manual)?                              │
     │    │       └── YA → tampilkan HPP read-only + Price Advisor   │
     │    │       └── TIDAK → tampilkan nudge "Atur HPP ▼"           │
     │    │                                                           │
     │    └── Ada PatternSpec aktif?                                  │
     │            └── YA → toggle "Kurangi bahan" (default ON)       │
     │            └── TIDAK → tidak ada toggle                        │
     │                                                                │
     └── [Alasan = "Koreksi Stok"] → form standar tanpa HPP ─────────┘

[Simpan]
  → adjustStock ATAU addStockFromBahan (tergantung toggle + spec)
  → PATCH product_size (jika HPP diisi dan/atau harga dipilih)
```
