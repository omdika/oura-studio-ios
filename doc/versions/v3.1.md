# v3.1 — Tambah Produk Lengkap: Produk + Resep dalam Satu Alur (2026-08-10)

**Changed by:** Frontend  
**Sections affected:** Section 2 (Tab Produk → ProdukListView)

---

## Summary

FAB "+" di tab Produk sebelumnya hanya membuat produk kosong (nama + SKU + ukuran). User harus pergi ke tab Resep secara terpisah untuk mengisi resep. Fitur ini menggabungkan keduanya dalam satu sheet two-step.

---

## Perubahan

### Sheet baru: `TambahProdukLengkapSheet`

Menggantikan `AddProductSheet` (private struct yang kini dihapus dari `ProdukListView.swift`). Memiliki dua step dalam satu sheet:

**Step 1 — Detail Produk:**
- Nama produk + SKU (auto-generate dari nama, bisa diubah manual)
- Preset ukuran (Free Size / XS–XL / S–XXL) + token chip per ukuran + ukuran kustom
- Tombol "Lanjutkan ke Resep →" (primary, enabled jika nama + SKU + ukuran terisi)
- Tombol "Simpan Tanpa Resep" (secondary/outlined) — membuat produk + sizes langsung tanpa recipe

**Step 2 — Resep (opsional):**
- Header: `[← Produk]  Tambah Resep` — back button kembali ke step 1
- **Picker ukuran** (hanya muncul jika user memilih >1 ukuran di step 1): chip row untuk memilih ukuran mana yang diresep sekarang. Ukuran lain bisa diresep nanti dari tab Resep.
- **Kain** (opsional): `TokenizedMultiSelectField` + dimensi panjang/lebar + toggle rotasi per kain
- **Toggle Gabungkan** (muncul jika 2+ kain): sama persis dengan `TambahResepSheet`
- **Komponen tambahan** (opsional): hardware/benang/packaging + qty per unit
- **Tenaga Kerja**: estimasi waktu kerja (menit)
- Tombol "Simpan Produk & Resep" (primary, enabled jika labor > 0 dan semua dimensi kain terisi)
- Tombol "Simpan Tanpa Resep" (secondary text button) — escape hatch dari step 2

---

## Logic Save

**"Simpan Tanpa Resep":** `createProduct` + `createProductSize` untuk semua ukuran → dismiss.

**"Simpan Produk & Resep":**
1. `createProduct` + `createProductSize` untuk semua ukuran (base, tanpa `fabricVariantName`)
2. Lookup base size untuk `recipeSize`
3. Jika `selectedFabricIds.isEmpty || gabungkanResep`: satu `PatternSpec` di base size dengan semua kain (atau tanpa kain jika kosong)
4. Jika pisah (2+ kain, gabungkan=false): untuk setiap kain, `createProductSize` dengan `fabricVariantName = fabric.name`, lalu satu `PatternSpec` per variant size

Logic ini identik dengan `TambahResepSheet.save()` — tidak ada perbedaan behavior.

---

## Keputusan Desain

**Multi-ukuran → resep untuk satu ukuran dulu.** Dimensi kain hampir selalu berbeda per ukuran (produk pakaian). Membuat PatternSpec identik untuk semua ukuran sekaligus akan menghasilkan HPP yang salah. User memilih satu ukuran untuk diresep sekarang; ukuran lain diresep dari tab Resep.

**Tab Resep tidak berubah.** `TambahResepSheet` tetap ada dan tetap digunakan untuk menambah resep ke produk yang sudah ada.
