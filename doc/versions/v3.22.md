## Latar Belakang

Owner ingin memantau performa penjualan varian produk secara mendalam untuk mengetahui produk mana saja yang paling laris (*best-seller*) berdasarkan jumlah unit terjual. 

v3.22 menambahkan menu laporan baru **"Ranking Penjualan Produk"** di halaman **Lainnya** (Laporan) di bawah menu "Laporan Penjualan". Laporan ini mendukung penyaringan berdasarkan rentang tanggal yang dipilih menggunakan komponen `DateRangeField`. Data penjualan akan diambil dari database, dikelompokkan per ukuran & varian kain, lalu diurutkan dari yang paling laris.

### 2. Tampilan Baru `SalesByProductRankingView`
Layar ini diimplementasikan menggunakan arsitektur standard halaman laporan yang dinamis:

*   **Penyaring Rentang Tanggal (`DateRangeField`):**
    - Tersemat di bagian atas layar di dalam `ouraCard`.
    - Menggunakan binding `@State private var fromDate` (default 30 hari yang lalu) dan `@State private var toDate` (default hari ini).
    - Memicu pemuatan ulang data (`load()`) setiap kali tanggal diubah.
*   **Indikator Loading, Error, dan Kosong:**
    - `ProgressView` saat mengambil data dari API.
    - `reportErrorView(icon: "crown.fill", message: errorMsg)` saat terjadi kegagalan API.
    - `reportEmptyView(icon: "crown.fill", title: "Belum ada data penjualan", subtitle: "Data penjualan akan muncul setelah ada pesanan selesai pada periode ini")` jika hasil query kosong.
*   **Daftar Ranking (Urutan Terlaris):**
    - Ditampilkan dalam format list vertikal yang bersih.
    - Setiap baris memiliki komponen:
        - **Nomor Urut Peringkat:** Teks `#1`, `#2`, `#3` dst. Peringkat 1-3 menggunakan warna `OuraTheme.Colors.accent` untuk visualisasi pemenang (*highlight*), peringkat selebihnya memakai warna `textTertiary`.
        - **Label Identitas Produk:** Nama produk lengkap dengan ukuran dan varian bahan (menggunakan computed property `.displayLabel` dari `SalesByProductItem` yaitu `Nama Produk · Ukuran · Varian Kain`).
        - **Detail Statistik Penjualan:** Teks sekunder yang menampilkan total Pendapatan (Revenue) dan total Profit dari varian tersebut (misal: `Pendapatan: Rp 450.000 · Profit: Rp 210.000`).
        - **Badge Kuantitas Terjual:** Angka kuantitas terjual di sebelah kanan dalam format menonjol (misal: `42 unit` / `terjual`).

## B. Spesifikasi API & Perubahan Backend (`../backend`)

Aplikasi iOS telah memodelkan `SalesByProductItem` dan memanggil `/reports/sales-by-product` pada `APIService.swift` di frontend. Untuk menyelaraskan ini, backend API harus diimplementasikan.

### 1. Model Skema Pydantic (`app/schemas/reports.py`)
Tambahkan skema respons baru:

```python
class ProductSalesRankingEntry(BaseModel):
    product_size_id: uuid.UUID
    product_name: str
    size_label: str
    fabric_variant_name: str | None
    qty_sold: int
    revenue: float
    profit: float
```

### 2. Penambahan Router Endpoint (`app/routers/reports.py`)
Tambahkan endpoint baru di bawah `/reports` prefix:

```python
@router.get("/sales-by-product", response_model=list[ProductSalesRankingEntry])
def product_sales_ranking(
    from_: date | None = Query(default=None, alias="from"),
    to: date | None = Query(default=None),
    db: Session = Depends(get_db),
):
    if from_ is None or to is None:
        raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail="from and to are required")
    if from_ > to:
        raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail="from must be <= to")

    start = datetime.combine(from_, datetime.min.time(), tzinfo=timezone.utc)
    end = datetime.combine(to, datetime.min.time(), tzinfo=timezone.utc) + timedelta(days=1)

    # Melakukan query dan pengelompokan penjualan
    # Menghubungkan: SalesOrderItem -> SalesOrder (filter status != 'cancelled' dan tanggal)
    # Join ke: ProductSize -> Product
    from sqlalchemy import func

    results = (
        db.query(
            ProductSize.id.label("product_size_id"),
            Product.name.label("product_name"),
            ProductSize.size_label.label("size_label"),
            ProductSize.fabric_variant_name.label("fabric_variant_name"),
            func.sum(SalesOrderItem.qty).label("qty_sold"),
            func.sum((SalesOrderItem.unit_price - SalesOrderItem.discount) * SalesOrderItem.qty).label("revenue"),
            func.sum(SalesOrderItem.line_profit).label("profit"),
        )
        .join(SalesOrderItem, ProductSize.id == SalesOrderItem.product_size_id)
        .join(SalesOrder, SalesOrderItem.sales_order_id == SalesOrder.id)
        .join(Product, ProductSize.product_id == Product.id)
        .filter(
            SalesOrder.sold_at >= start,
            SalesOrder.sold_at < end,
            SalesOrder.status != "cancelled"
        )
        .group_by(
            ProductSize.id,
            Product.name,
            ProductSize.size_label,
            ProductSize.fabric_variant_name
        )
        .order_by(func.sum(SalesOrderItem.qty).desc())
        .all()
    )

    return [
        ProductSalesRankingEntry(
            product_size_id=r.product_size_id,
            product_name=r.product_name,
            size_label=r.size_label,
            fabric_variant_name=r.fabric_variant_name,
            qty_sold=int(r.qty_sold),
            revenue=float(r.revenue),
            profit=float(r.profit),
        )
        for r in results
    ]
```
