# Version 3.80 - Search Produk di Ekspor XLSX Shopee (Mode Pilih Produk)

## 1. Problem / Opportunity
*   **Context:** Fitur v3.79 menambahkan mode "Pilih Produk Tertentu" di `ShopeeBulkUploadSheet` dengan daftar semua produk non-archived dan checkbox. Saat jumlah produk banyak (mis. 88 produk), pengguna harus-scroll panjang untuk mencari produk yang ingin dicentang. Tidak ada cara cepat untuk menemukan produk berdasarkan nama atau SKU.
*   **Objective:** Menambahkan textbox search di bagian mode "Pilih Produk Tertentu" sehingga pengguna dapat dengan cepat mencari produk by name atau SKU sebelum mencentang untuk diekspor ke Excel Shopee.

## 2. Decision (Final)
*   **Pilihan: Opsi A** — Search textbox client-side only, hanya muncul di mode "Pilih Produk Tertentu", selection persists saat difilter, dan "Pilih Semua/Kosongkan" hanya mempengaruhi produk yang terlihat (terfilter).
*   **Alasan:**
    1. Produk sudah dimuat ke memori (`products`) saat sheet muncul → filter instan, tidak perlu panggilan backend tambahan.
    2. Selection persists memastikan produk yang sudah dicentang tidak hilang saat pengguna mencari produk lain.
    3. Tidak perlu perubahan backend/API (frontend-only).
*   **Opsi B (tidak dipilih):** Search memanggil backend lagi — ditangguhkan karena menambah latency dan perlu endpoint baru.

## 3. Database Schema Changes
*   Tanpa perubahan database.

## 4. API Contract (FastAPI)
*   Tanpa perubahan endpoint. Menggunakan endpoint existing `GET /products/shopee-bulk-upload?product_ids=` dari v3.79.

## 5. Frontend Changes (SwiftUI)

### 5.1 `Screens/Produk/ShopeeBulkUploadSheet.swift`
*   **State baru:**
    *   `searchText: String = ""` — kata kunci search produk (name / SKU).
*   **Perbaikan keyboard (bug fix):**
    *   Seluruh konten dibungkus dalam `ScrollView` dengan `.ignoresSafeArea(.keyboard)` dan `.scrollDismissesKeyboard(.interactively)` sehingga list produk dapat di-scroll dan tidak tertutup keyboard saat muncul.
    *   Ditambahkan `simultaneousGesture(TapGesture())` yang memanggil `UIApplication.shared.resignFirstResponder` sehingga keyboard dapat ditutup saat mengetap area di luar field input.
*   **UI baru (hanya saat `exportMode == .selection`):**
    *   Textbox search di atas daftar produk, di bawah ringkasan "Pilih Semua / Kosongkan".
    *   Placeholder: `"Cari nama atau SKU..."`.
    *   Tombol clear (`xmark`) saat search tidak kosong.
*   **Logika filter:**
    *   `filteredProductsForSelection: [Product]` = `allNonArchivedProducts` difilter by `name` atau `sku` (localizedCaseInsensitiveContains).
    *   Daftar checkbox ditampilkan dari `filteredProductsForSelection`, bukan `allNonArchivedProducts`.
    *   `selectedProductIds` **tidak direset** saat search berubah (selection persists).
    *   Tombol "Pilih Semua / Kosongkan" mempengaruhi hanya produk dalam `filteredProductsForSelection` (yang terlihat).
    *   Ringkasan tetap `"\(selectedProductIds.count) dari \(allNonArchivedProducts.count) produk"` (total semua, bukan hanya terfilter).
*   **Tombol unduh:** tetap nonaktif saat `selectedProductIds.isEmpty`.

## 6. Verification & Test Plan
*   **Smoke Test:** App build sukses (`xcodebuild`); sheet Ekspor Shopee terbuka; toggle ke mode "Pilih Produk Tertentu" menampilkan textbox search tanpa crash.
*   **Sanity Test Scenarios:**
    1. Mode "Pilih Produk Tertentu" → ketik nama produk (mis. "boneka") → daftar menyaring hanya produk yang cocok; produk lain disembunyikan.
    2. Ketik SKU (mis. "TC004") → daftar menyaring berdasarkan SKU.
    3. Centang produk → ubah search → centang produk lain → kembali ke search pertama → produk pertama **masih tercentang** (selection persists).
    4. Ketik search yang tidak cocok apapun → daftar kosong, tidak ada checkbox; tombol unduh tetap nonaktif jika tidak ada selection.
    5. Tekan "Pilih Semua" saat search aktif → hanya produk yang terlihat (terfilter) yang tercentang.
    6. Hapus search (clear / kosongkan) → semua produk non-archived kembali muncul; selection tetap utuh.
