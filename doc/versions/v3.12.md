## Latar Belakang

Tiga gap yang diperbaiki sekaligus:

1. **Draft batch HPP disappearing:** setiap kali user expand item di draft batch dan qty berubah (termasuk saat `onAppear`), HPP breakdown yang sudah ada ikut hilang karena API response untuk PATCH item tidak menyertakan `latest_hpp_breakdown` — field itu kosong di draft status.

2. **Confirmed batch tidak menampilkan HPP rincian:** card batch yang sudah dikonfirmasi hanya menampilkan nama produk dan qty, tanpa akses ke breakdown HPP. User tidak bisa cek komponennya setelah konfirmasi.

3. **Price Advisor terlalu jauh dari titik keputusan:** flow sebelumnya mengharuskan user keluar ke tab Produk → pilih size → buka Price Advisor. User sering konfirmasi batch tanpa pernah mengatur harga jual, sehingga HPP sudah ada tapi harga jual = 0.

## Perubahan Frontend

### 1. enrichDraftHpp — HPP client-side untuk draft batch

Fungsi baru `enrichDraftHpp(_ batches:)` yang dipanggil setelah `load()`. Untuk setiap item di draft batch yang `hppTotal == 0`, fungsi:
1. Lookup `PatternSpec` aktif untuk `productSizeId` item
2. Hitung fabric cost dari spec materials × `MaterialPurchase.currentAvgCost`
3. Ambil labor, overhead, pooled rates dari `settings`
4. Buat `HPPBreakdown` client-side dan assign ke `item.latestHppBreakdown`

Ini hanya estimasi (menggunakan current avg cost, bukan locked cost saat batch dibuat) — ditampilkan dengan prefix "~" dan catatan "estimasi".

### 2. effectiveHpp(for:) — fallback helper

```swift
private func effectiveHpp(for item: ProductionBatchItem) -> HPPBreakdown? {
    if let bd = item.latestHppBreakdown { return bd }
    if item.hppTotal > 0 {
        return HPPBreakdown(fabric: item.hppFabric, pooledMaterial: item.hppPooledMaterial,
                            hardware: item.hppHardware, labor: item.hppLabor,
                            overhead: item.hppOverhead, total: item.hppTotal)
    }
    return nil
}
```

Fallback chain: `latestHppBreakdown` → konstruksi dari `hpp*` flat fields → nil.

### 3. updateItem — preserve latestHppBreakdown setelah PATCH

`PATCH /production-batches/{id}/items/{item_id}` mengembalikan item bare tanpa HPP breakdown (karena status masih draft). Sebelumnya `updateItem()` langsung replace item dengan API response sehingga HPP menghilang. Fix: simpan `existing.latestHppBreakdown` dan restore ke item baru dari API.

```swift
private func updateItem(_ updated: ProductionBatchItem, in batchId: UUID) {
    // ...
    let existing = batches[bi].items[ii]
    batches[bi].items[ii] = updated
    if updated.latestHppBreakdown == nil {
        batches[bi].items[ii].latestHppBreakdown = existing.latestHppBreakdown
    }
}
```

### 4. BatchItemRow.onChange guard

```swift
.onChange(of: qty) { _, q in
    guard q != item.qtyActual else { return }
    // API call
}
```

Guard `q != item.qtyActual` mencegah API call spurious pada `onAppear` (SwiftUI memanggil `onChange` ketika binding diinitialize).

### 6. PriceAdvisorSection — inline per varian

Private struct yang ditampilkan di dalam `BatchCard` (draft) dan `ConfirmedBatchCard` setelah HPP rincian item yang sedang di-focus.

Collapsed state: satu baris `"Price Advisor · Rp X"` — suggested price langsung terlihat tanpa perlu expand.

Expanded state: dua input field (`TextField`) untuk Margin (%) dan Marketplace Fee (%), live calculation:
```
suggestedPrice = ceil(hpp.total / (1 - (margin + fee) / 100))
resultingMarkupPct = (suggestedPrice - hpp.total) / hpp.total × 100
resultingMarginPct = (suggestedPrice - hpp.total) / suggestedPrice × 100
```

Tombol "Gunakan Harga Ini" memanggil `onApply(price)` callback → `applyPrice(item:price:)`.

Default: margin 40%, fee 0%.

### 7. applyPrice — PATCH selling_price ke backend

```swift
private func applyPrice(item: ProductionBatchItem, price: Double) async {
    guard let sizeId = item.productSizeId,
          let sku = skuMap[sizeId] else { return }
    _ = try? await api.patchProductSize(sku: sku, sizeId: sizeId,
                                        PatchProductSizeRequest(sellingPrice: price))
}

private var skuMap: [UUID: String] {
    Dictionary(patternSpecs.map { ($0.productSizeId, $0.productSku) },
               uniquingKeysWith: { a, _ in a })
}
```

`skuMap` di-derive dari `patternSpecs` yang sudah diload — tidak ada API call tambahan.

### 8. Auto-apply pada Konfirmasi

Saat user tap "Konfirmasi & Tambah ke Stok", setelah `confirmBatch` selesai, semua item yang punya HPP langsung diapply harga sarannya (40% margin):

```swift
await withTaskGroup(of: Void.self) { group in
    for item in batch.items {
        let hpp = item.latestHppBreakdown?.total
            ?? (item.hppTotal > 0 ? item.hppTotal : nil)
        guard let hpp, hpp > 0, item.productSizeId != nil else { continue }
        let price = ceil(hpp / 0.6)  // 40% margin = hpp / (1 - 0.40)
        group.addTask { await self.applyPrice(item: item, price: price) }
    }
}
```

Ini memotong flow: sebelumnya user harus keluar ke tab Produk dan set harga manual untuk setiap size. Sekarang satu tap konfirmasi = batch confirmed + semua harga jual ter-set.
