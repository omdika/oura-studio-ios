# Version 3.79 - Opsi Pilih Produk di Ekspor XLSX Shopee

## 1. Problem / Opportunity
*   **Context:** Fitur "Ekspor Massal Shopee" di `ShopeeBulkUploadSheet` saat ini mengekspor **semua** produk non-archived kategori scrunchie dan pouch dengan satu tombol "Unduh Template Shopee". Pengguna tidak bisa memilih subset produk tertentu, sehingga file Excel yang dihasilkan sering berisi produk yang tidak ingin diunggah ke Shopee.
*   **Objective:** Menambahkan opsi pemilihan produk di fitur export XLSX Shopee di halaman Produk, dengan dua mode: "Ekspor Semua (scrunchie+pouch)" (perilaku existing) dan "Pilih Produk Tertentu" (produk yang dicentang saja). Pilihan produk dikirim ke backend agar file Excel hasil unduh sudah difilter.

## 2. Decision (Final)
*   **Pilihan: Opsi A** — Frontend + Backend. Endpoint `GET /products/shopee-bulk-upload` menerima query parameter opsional `product_ids` (daftar UUID terpisah koma). Jika ada, backend hanya sertakan produk terpilih di Excel; jika tidak, perilaku existing (semua scrunchie + pouch non-archived).
*   **Alasan:**
    1. Menjawab permintaan pengguna secara langsung: opsi pilih produk di halaman Produk.
    2. File Excel yang dihasilkan sudah difilter di backend → siap unggah ke Shopee tanpa editing ulang di iOS.
    3. Mode "Ekspor Semua" tetap dipertahankan untuk kompatibilitas mundur.
*   **Opsi B (tidak dipilih):** Frontend-only — unduh semua lalu filter seleksi di iOS setelah file ada. Ditangguhkan karena file hasil unduh tetap berisi semua produk dan tidak efisien.

## 3. Database Schema Changes
*   Tanpa perubahan database. Data produk dibaca dari tabel existing (`product`, `product_size`).

## 4. API Contract (FastAPI)
*   **Endpoint:** `GET /products/shopee-bulk-upload`
*   **Query parameter baru (opsional):** `product_ids` = daftar UUID produk terpilih, terpisah koma (contoh: `?product_ids=uuid1,uuid2,uuid3`).
*   **Perilaku:**
    *   Jika `product_ids` disediakan: hanya sertakan produk dengan ID yang cocok (dan non-archived) di file Excel.
    *   Jika `product_ids` tidak disediakan: perilaku existing (semua produk non-archived kategori scrunchie + pouch).
*   **Validasi & Error:** ID yang tidak ditemukan atau diabaikan (tidak menjadi error); jika semua ID tidak valid → kosong / file kosong dengan pesan. Respons tetap `.xlsx` dan status 200 saat berhasil.

## 5. Frontend Changes (SwiftUI)

### 5.1 `Screens/Produk/ShopeeBulkUploadSheet.swift`
*   **State baru:**
    *   `exportMode: ExportMode` = `.all` (default) atau `.selection`
    *   `selectedProductIds: Set<UUID>` = produk yang dicentang (hanya berlaku mode selection)
    *   `allProducts: [Product]` = semua produk non-archived (untuk daftar pilihan, bukan hanya scrunchie+pouch)
*   **UI baru:**
    *   Picker/Toggle "Mode Ekspor": "Semua Produk Scrunchie & Pouch" vs "Pilih Produk Tertentu".
    *   Saat `.selection`: tampilkan daftar produk non-archived dengan checkbox (nama + SKU + kategori), ringkasan jumlah terpilih, tombol "Pilih Semua / Kosongkan".
    *   Tombol "Unduh Template Shopee" **dinonaktifkan** saat mode `.selection` dan `selectedProductIds` kosong.
*   **Action `downloadExcel`:** kirim `selectedProductIds` ke `api.downloadShopeeBulkUploadExcel(productIds:)` saat mode `.selection`; kirim `nil` saat `.all`.
*   Ringkasan produk siap ekspor tetap ditampilkan (scrunchie + pouch count) sebagai referensi.

### 5.2 `Networking/APIService.swift`
*   Ubah signature: `func downloadShopeeBulkUploadExcel(productIds: [UUID]? = nil) async throws -> URL`.
*   Jika `productIds` tidak nil, tambahkan query item `product_ids` (join UUID uuidString dengan koma) ke URL `baseURL + "/products/shopee-bulk-upload"`.
*   Sisa logika download & simpan file ke Documents tetap sama.

### 5.3 `Networking/MockAPIService.swift`
*   Ubah signature sesuai `APIService`. Terima `productIds` (abaikan isinya untuk mock, tetap kembalikan file dummy) agar compile dan preview tidak error.

### 5.4 `Screens/Produk/ProdukListView.swift`
*   Tanpa perubahan (titik entri toolbar "Ekspor Shopee" tetap membuka `ShopeeBulkUploadSheet`).

## 6. Verification & Test Plan
*   **Smoke Test:** App build sukses (`xcodebuild`); halaman Produk → tombol Ekspor Shopee → sheet terbuka tanpa crash; toggle mode berfungsi.
*   **Sanity Test Scenarios:**
    1. Mode default `.all` → tekan Unduh → file Excel berisi semua scrunchie+pouch non-archived (perilaku existing tetap utuh).
    2. Mode `.selection` → pilih 2–3 produk → tekan Unduh → `APIService` dipanggil dengan `product_ids` yang benar; file diterima dan dapat dibagikan (share sheet).
    3. Mode `.selection` → tidak pilih produk apa-apa → tombol Unduh **tidak aktif (disabled)**.
    4. Mode `.selection` → "Pilih Semua" → semua produk tercentang → tombol Unduh aktif.
    5. Mock mode: pemanggilan tidak error walaupun `productIds` dikirim.
