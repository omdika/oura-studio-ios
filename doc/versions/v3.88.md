# Version 3.88 - Optimasi Tampilan Filter Kategori Produk List (Chip "All" + Kompak)

## 1. Problem / Opportunity
*   **Context:** Fitur filter kategori v3.87 (`ProdukListView`, `ChipSingleSelect`) sudah bekerja, tetapi memiliki dua kelemahan UX: (1) opsi **"All" tidak ada sebagai chip yang bisa dipilih** — state `.all` hanya internal default; setelah user memilih "Pouch" atau "Scrunchie", tidak ada cara cepat untuk kembali ke "All" lewat UI chip. (2) Tampilan filter kategori **terlalu besar, tidak proporsional, dan memakan tempat vertikal**: `categoryFilterSection` bungkus `.ouraCard()` (radius 18) dengan padding `cardPad` 16 di setiap sisi, `ChipSingleSelect` masih render label Text (meskipun kosong) + spacing 10 + chip padding vertical 7, sehingga kotak filter terasa berlebihan untuk hanya 2-3 opsi kategori.
*   **Objective:** Tambah chip **"All" sebagai opsi pilihan yang terlihat dan bisa diklik**, serta **perkecil/kompakan tampilan filter kategori** agar lebih proporsional dan hemat ruang vertikal di layar produk, tanpa mengubah perilaku filter (server-side `?category=`) dan tanpa merusak pemakaian `ChipSingleSelect` di layar lain.

## 2. User Flow & UX Specifications
*   **Entry Point:** Halaman Produk (tab Produk), area filter kategori di bawah search header, di atas kartu total.
*   **UI Components:** `ChipSingleSelect` dengan parameter opsional `compact: Bool = false`. Saat `compact = true`: chip font 12, padding horizontal 10 / vertical 6, spacing 6, tanpa label Text terpisah (label ditangani section header yang lebih kecil).
*   **Opsi "All":** Masukkan `.all` ke dalam daftar opsi chip (jangan `filter { $0 != .all }`). Chip "All" selalu ada dan dapat dipilih; saat terpilih (accent), berarti semua kategori ditampilkan. Saat tidak ada yang terpilih / "All" aktif → `selectedCategory = .all`.
*   **Label section:** Text "Kategori" diperkecil (font 12, weight regular, textSecondary) dengan padding vertikal lebih kecil (top 4 / bottom 6) agar tidak memakan tempat.
*   **Perilaku filter:** Tidak berubah — `selectedCategory == .all` kirim tanpa parameter `category`; selain itu kirim `?category=pouch|scrunchie`. `onChange(of: selectedCategory)` → `requestReload(force: true)`. Kombinasi dengan search + filter tanggal tetap dipertahankan.
*   **State:** `@State private var selectedCategory: ProductCategory = .all` tetap. Binding adaptor `selectedCategoryBinding` tetap (nil = all).

## 3. Database Schema Changes (FastAPI / SQLAlchemy)
*   **Tidak ada migration baru.** Tidak ada perubahan database.

## 4. API Contract (FastAPI)
*   **Tidak ada perubahan endpoint.** Pakai `GET /products?category=` dan `GET /products/stats?category=` existing dari v3.87.

## 5. Frontend Changes (SwiftUI)
*   **`Components/ChipSingleSelect.swift`**:
    *   Tambah parameter `compact: Bool = false`.
    *   Jika `compact == true`: chip font `.system(size: 12, weight: .semibold)`, padding horizontal 10 / vertical 6, HStack spacing 6, VStack spacing 6, skip render `Text(label)` (biarkan label ditangani caller/section).
    *   Jika `compact == false`: perilaku existing (tidak ada breaking change untuk caller lain).
*   **`Screens/Produk/ProdukListView.swift`**:
    *   `categoryFilterSection`:
        *   `options: ProductCategory.allCases.map { ... }` (masukkan `.all`, jangan exclude).
        *   Pakai `ChipSingleSelect(label: "", selected: selectedCategoryBinding, options: ..., compact: true)`.
        *   Hapus `.ouraCard()` wrapper (gunakan background ringan / hapus card tebal), kurangi `VStack(alignment: .leading, spacing: 10)` → spacing 6.
        *   Text "Kategori": font 12, weight regular, padding vertikal lebih kecil.
        *   Padding bottom section diperkecil (8 alih-alih 16).
    *   `selectedCategoryBinding`: tetap (nil = all).
    *   `onChange(of: selectedCategory)` → `requestReload(force: true)` tetap.
*   **Tidak perlu ubah:** `ProductModels.swift`, `APIService.swift` (parameter category sudah ada v3.87), `MockAPIService.swift`.

## 6. Verification & Test Plan
*   **Smoke Test:** `xcodebuild` sukses. Buka tab Produk → chip kategori tampil dengan opsi "All / Pouch / Scrunchie" dalam satu baris horizontal ringan, "All" default aktif, list produk muncul, total card tampil. Tampilan filter kategori lebih sempit vertikal dari sebelum.
*   **Sanity Test Scenarios:**
    1.  Default "All" aktif saat masuk → semua produk non-archived muncul; chip "All" ditandai aktif.
    2.  Tap chip "Pouch" → hanya produk pouch; chip "Pouch" accent terpilih, "All" tidak terpilih; total card menurun sesuai.
    3.  Tap chip "All" lagi → kembali ke semua produk; chip "All" accent terpilih; total kembali ke nilai global.
    4.  Tap chip "Scrunchie" → hanya produk scrunchie; total dan list menyesuaikan.
    5.  Kombinasi kategori + search + filter tanggal → semua filter tetap saling menghormati (interseksi).
    6.  **Proporsi tampilan:** Tinggi area filter kategori lebih sempit dari v3.87 (tanpa ouraCard tebal + padding 16); chip "All" terlihat sejajar dengan Pouch/Scrunchie.
    7.  **Regression layar lain:** `ChipSingleSelect` yang dipakai layar lain (non-compact) tetap tampil normal (no breaking change).
*   **Test case terkait:** `test/docs/TC-009-filter-kategori-produk.md`.
