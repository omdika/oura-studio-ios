**Status:** PLANNED
**Date:** 2026-08-26
**Changed by:** Design + Frontend
**Backend changes required:** None (Purely client-side layout stabilization of `BerandaView.swift`).

---

## Latar Belakang

Saat aplikasi pertama kali dibuka atau di-refresh, data dashboard diunduh secara asinkron dari API backend. Selama durasi loading ini (`isLoading == true`), data peringatan stok belum tersedia, sehingga seksi **Peringatan Stok** disembunyikan sepenuhnya dari layar. 

Hal ini menyebabkan seksi **Kasir Penjualan Kilat** (Catat Penjualan & Scan & Jual) bergeser naik ke area atas. Ketika loading selesai dan data diisi, seksi Peringatan Stok mendadak muncul, mendesak seksi Kasir Penjualan Kilat kembali ke bawah. Pergeseran letak secara tiba-tiba (*layout shift*) ini merusak keindahan UI dan membuat posisi tombol tidak stabil untuk di-tap.

v3.33 memperkenalkan **Tampilan Preload Peringatan Stok (Skeleton/Preload State)**:
1.  **Skeleton Section Sesuai Dimensi Asli:** Menampilkan seksi Peringatan Stok bayangan selama `isLoading` aktif dengan layout, judul, dan scrollable card yang identik secara visual dengan versi aslinya.
2.  **Dimensi Presisi Tanpa Pergeseran:** Menyusun kartu bayangan (*skeleton card*) dengan frame `width: 260` and `height: 46` yang tepat sama seperti kartu asli, sehingga layout penampung terisi sejak awal dan posisi Kasir Penjualan Kilat tetap kokoh di tempatnya (*stable layout*).
3.  **Animasi Halus & Gaya OuraTheme:** Kartu preload menggunakan warna adaptif dari `OuraTheme.Colors.surfaceCard` dan elemen placeholder semi-transparan yang elegan, memberikan pengalaman pemuatan yang modern dan premium.

## A. Desain UI & Penataan Ulang Dashboard (`BerandaView.swift`)

### 1. Perubahan Kondisi Render Seksi Peringatan Stok
Sebelumnya seksi peringatan stok hanya dirender jika dashboard sudah terisi dan tidak kosong:
```swift
if let dash = dashboard, !dash.lowStockAlerts.isEmpty {
    stockAlertsSection(dash.lowStockAlerts)
}
```

Sekarang, kita ubah agar dirender baik saat sedang loading (`isLoading == true`), maupun saat data sudah ada dan memiliki peringatan stok:
```swift
if isLoading {
    stockAlertsSkeletonSection
} else if let dash = dashboard, !dash.lowStockAlerts.isEmpty {
    stockAlertsSection(dash.lowStockAlerts)
}
```

### 2. Implementasi `stockAlertsSkeletonSection` and `stockAlertSkeletonCard`
*   **`stockAlertsSkeletonSection`:** Merender judul "Peringatan Stok" dengan badge item skeleton, diikuti oleh `ScrollView(.horizontal, showsIndicators: false)` berisi 2-3 buah `stockAlertSkeletonCard` berjajar horizontal.
*   **`stockAlertSkeletonCard`:** Memiliki ukuran presisi `width: 260` and `height: 46`, sudut membulat `12pt`, border `OuraTheme.Colors.border`, dan background `OuraTheme.Colors.surfaceCard`. Di dalamnya diletakkan:
    *   Satu lingkaran placeholder untuk icon dengan opacity `0.1` atau warna border.
    *   Dua baris persegi panjang tipis (`RoundedRectangle`) sebagai placeholder tulisan nama produk dan rincian ukuran dengan warna `OuraTheme.Colors.textSecondary.opacity(0.1)`.
    *   Satu kapsul placeholder di sebelah kanan untuk badge status "Habis/Menipis" dengan warna netral tipis.
