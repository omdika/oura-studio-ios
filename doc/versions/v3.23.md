v3.23 mengimplementasikan tampilan kartu statistik horizontal (`summaryHeaderView`) yang disematkan di bagian atas daftar produk. Metrik ini dihitung secara real-time dari kumpulan data aktif produk dan ukuran.

---

## A. Detail Implementasi UI & Metrik

### 1. Perhitungan Metrik (Client-side Math)
Metrik berikut dihitung secara dinamis dari properti `@State private var products` dan `allSizes`:
- **Total Produk:** Jumlah jenis produk aktif (`products.filter { !$0.isArchived }.count`).
- **Total Stok:** Jumlah total stok fisik teragregasi (`allSizes.filter { !$0.isArchived }.reduce(0) { $0 + $1.currentStockQty }`).
- **Stok Kosong:** Jumlah varian ukuran aktif yang saat ini kehabisan stok (`allSizes.filter { !$0.isArchived && $0.currentStockQty == 0 }.count`).

### 2. Komponen Kartu Ringkasan (`statCard`)
Setiap metrik dibungkus dalam `statCard` kustom horizontal:
- **Total Produk:** Menggunakan ikon `tag.fill`, warna `blueAccent` dan latar `blueBg`.
- **Total Stok:** Menggunakan ikon `shippingbox.fill`, warna `accent` dan latar `accentLight`.
- **Stok Kosong:** Menggunakan ikon `slash.circle.fill`, warna `dangerText` dan latar `dangerBg`.

Desain disesuaikan sepenuhnya dengan standar `OuraTheme` (sudah mendukung mode gelap/terang secara adaptif).
