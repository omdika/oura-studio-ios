# v3.35 — Penambahan Total Pcs Terjual di Laporan Penjualan

**Status:** PLANNED
**Date:** 2026-08-26
**Changed by:** Frontend
**Backend changes required:** None (Didesain kompatibel dengan API saat ini, dengan fallback cerdas).

---

## Latar Belakang

Owner ingin memantau total jumlah produk fisik (*pieces* atau *pcs*) yang terjual pada halaman **Laporan Penjualan** (tab Lainnya). Saat ini, bagian **Per Periode** hanya menampilkan Pendapatan dan jumlah Transaksi (misal: `26 transaksi`), tetapi tidak merinci total unit barang yang terjual pada tanggal/periode tersebut.

v3.35 mengimplementasikan penambahan kuantitas produk terjual pada dua area di halaman Laporan Penjualan:
1.  **Seksi Per Periode (Daftar Harian):** Menampilkan rincian total pcs terjual berdampingan dengan jumlah transaksi (misal: `26 transaksi · 35 pcs`).
2.  **Seksi Ringkasan (Summary Card):** Menambahkan total kuantitas produk terjual selama keseluruhan periode waktu yang dipilih (misal: `Total Pcs Terjual: 45 pcs`) dihitung dari akumulasi kuantitas produk terjual pada seksi Per Barang.

## Spesifikasi Teknis & Alur Data

### 1. Ekstensi Model `SalesReportPoint` (`ReportsModels.swift`)
Menambahkan properti opsional `unitsSold` yang dipetakan ke field JSON `units_sold` dari API backend. Penggunaan tipe opsional `Int?` menjamin bahwa jika live backend belum mengembalikan data ini, pemisahan data (*decoding*) tidak akan mengalami kegagalan/crash (*backward-compatible*).

```swift
struct SalesReportPoint: Codable, Identifiable {
    let period: String
    let totalRevenue: Double
    let totalProfit: Double
    let orderCount: Int
    let unitsSold: Int? // Opsional untuk kompatibilitas ke belakang

    var id: String { period }

    enum CodingKeys: String, CodingKey {
        case period = "date"
        case totalRevenue
        case totalProfit
        case orderCount
        case unitsSold = "units_sold"
    }
}
```

### 2. Pemutakhiran Aggregation di `MockAPIService.swift`
Di dalam fungsi `getSalesReport`, lakukan perhitungan total pcs terjual untuk setiap hari/periode dengan menjumlahkan `qty` dari seluruh item pada transaksi di hari tersebut:

```swift
        var revenueByDay: [Date: Double] = [:]
        var profitByDay:  [Date: Double] = [:]
        var countByDay:   [Date: Int]    = [:]
        var unitsByDay:   [Date: Int]    = [:] // Baru: Simpan kuantitas harian
        
        for order in _salesOrders where order.status != "cancelled" {
            let day = cal.startOfDay(for: order.soldAt)
            guard day >= startDay && day <= endDay else { continue }
            revenueByDay[day, default: 0] += order.displayRevenue
            profitByDay[day,  default: 0] += order.displayProfit
            countByDay[day,   default: 0] += 1
            
            let totalQty = order.items.reduce(0) { $0 + $1.qty }
            unitsByDay[day, default: 0] += totalQty
        }
```

Lalu, masukkan nilai `unitsByDay` ke dalam inisialisasi `SalesReportPoint`.

### 3. Pemutakhiran UI di `ReportsView.swift`

*   **Pada Seksi Per Periode:**
    Ubah tampilan teks transaksi agar merinci jumlah pcs apabila data `unitsSold` tersedia:
    ```swift
    let transactionText = "\(point.orderCount) transaksi" + (point.unitsSold.map { " · \($0) pcs" } ?? "")
    Text(transactionText)
        .font(.system(size: 11))
        .foregroundStyle(OuraTheme.Colors.textTertiary)
    ```

*   **Pada Seksi Ringkasan:**
    Tambahkan total kuantitas produk terjual secara kumulatif dari seluruh produk terjual di periode tersebut (`byProduct.reduce(0) { $0 + $1.qtySold }`). Karena baris `summaryCell` menggunakan `HStack`, kita dapat menambahkan sel baru di samping `Transaksi` secara aman.
