# Version 3.70 - Instant Dashboard (Cache-First + Habis Saja + Smart Reload)

## 1. Problem / Opportunity
*   **Context:** `BerandaView.swift` saat ini memblokir seluruh dashboard di satu flag `isLoading` + satu call `GET /reports/dashboard`. Section `Peringatan Stok` me-render 243 card horizontal sekaligus (screenshot: "243 item"), sehingga kartu `Pendapatan Hari Ini` (todayRevenue, transaksi, item, margin) ikut terasa lambat. Pull-to-refresh (`.refreshable`) sudah ada, tapi tidak ada cache instan dan tidak ada auto-reload saat kembali ke tab Beranda.
*   **Objective:** (a) Kartu penjualan hari ini tampil instan (<16ms dari cache) lalu revalidasi background; (b) Section stok dashboard hanya tampilkan yang **Habis** (`currentStockQty == 0`), max 5 + "Lihat Semua"; (c) Pertahankan pull-to-refresh + tambah auto-reload saat kembali ke tab + sentinel reload saat scroll mentok bawah (debounced). Frontend-only, nol perubahan backend. Opsi Backend-slim (query param) dicatat sebagai **PENDING** di §7.

## 2. User Flow & UX Specifications
*   **Entry Point:** Tab `Beranda` (selectedTab == 0). Tidak ada navigasi baru.
*   **Buka tab (cache hit):**
    1. Render langsung dari cache (`dashboardCache`): sales card + stok Habis langsung terlihat, badge kecil "diperbarui X mnt lalu".
    2. Background: `loadDashboard(isBackground: true)` panggil `api.getDashboard()`, update UI diam-diam tanpa skeleton full.
*   **Buka pertama (cache kosong):** Tampilkan skeleton existing (`stockAlertsSkeletonSection` + placeholder revenue) — perilaku lama dipertahankan.
*   **Section Peringatan Stok (diubah):**
    *   Header: `Stok Habis` + kanan `N habis` (bukan 243 item). Jika nol habis → section disembunyikan total (atau empty state "Semua stok aman ✓" — pilih sembunyi agar hemat ruang).
    *   List: `lowStockAlerts.filter { $0.currentStockQty == 0 }.prefix(5)` horizontal, card existing `stockAlertCard` dipakai ulang tanpa ubah visual (tag "Habis" merah).
    *   Footer: tombol `Lihat semua (N)` → buka `StockOutAllSheet` (List vertikal penuh, SearchField existing, tiap row reuse `stockAlertCard` versi full-width).
*   **Reload behaviors (semua dipertahankan + ditambah):**
    *   Pull-to-refresh (existing `.refreshable`) → `loadDashboard(force: true)`.
    *   Auto-reload saat kembali ke tab: `.onChange(of: appState.selectedTab)` jika == 0 dan `lastRefresh > 60 detik` → background reload.
    *   Scroll-mentok reload: sentinel `Color.clear.frame(height: 1).onAppear` di dasar `ScrollView` → jika `>2 detik` sejak refresh terakhir → background reload. Wajib debounce + guard `isRefreshing` untuk cegah loop `onAppear`.
    *   `appState.dashboardNeedsRefresh` existing tetap (setelah tambah penjualan/pembelian) → force reload.
*   **UI Components:** Reuse `OuraSectionHeader`, `OuraTag`, `stockAlertCard`, `CurrencyInputField` tidak diperlukan. Tambah 1 sheet baru `StockOutAllSheet` + 1 helper `DashboardCache`.
*   **Validation Rules (`canSave`):** N/A (layar read-only, tidak ada form save).
*   **State & Progressive Disclosure:** N/A. Staged render: `dashboard` (cache) render duluan, `isRefreshing` hanya tampilkan `ProgressView` tipis di header badge, bukan skeleton full.

## 5. Frontend Changes (SwiftUI)
*   **Codable Models & APIService:** Tidak ada perubahan model (`DashboardSummary`, `LowStockAlert` tetap). Tidak ada perubahan `APIService.getDashboard()`.
*   **Baru: `Screens/Beranda/DashboardCache.swift`:**
    ```swift
    enum DashboardCache {
        static let key = "oura.dashboardCache.v1"
        static func load() -> (DashboardSummary, Date)? // JSONDecoder dari UserDefaults
        static func save(_ d: DashboardSummary) // JSONEncoder + Date.now
        static func minutesAgo(since: Date) -> String
    }
    ```
    *   `DashboardSummary` sudah `Codable` — langsung encode/decode, tidak perlu DTO baru.
*   **Edit: `Screens/Beranda/BerandaView.swift`:**
    *   State: tambah `@State lastRefresh: Date?`, `@State isRefreshing = false`, `@State showAllOut = false`. Ubah `isLoading` → hanya true jika `dashboard == nil && cache == nil`. Pisahkan: sales card baca `dashboard ?? cachedDashboard`.
    *   Computed: `var outOfStock: [LowStockAlert] { (dashboard?.lowStockAlerts ?? []).filter { $0.currentStockQty == 0 } }`, `var outCount: Int`.
    *   `loadDashboard(force:isBackground:)`:
        ```swift
        guard !isRefreshing else { return }
        if !isBackground && dashboard == nil { isLoading = true }
        else { isRefreshing = true }
        defer { isLoading = false; isRefreshing = false; lastRefresh = Date() }
        do { let fresh = try await api.getDashboard(); dashboard = fresh; DashboardCache.save(fresh) }
        catch { if dashboard == nil { errorMsg = ... } /* else: silent, keep cache */ }
        ```
    *   Lifecycle: `.task { if let (c, t) = DashboardCache.load() { dashboard = c; lastRefresh = t }; await loadDashboard(isBackground: dashboard != nil) }`. Tambah `.onChange(of: appState.selectedTab)` untuk auto-reload stale >60s.
    *   Stok section: ganti `stockAlertsSection(dash.lowStockAlerts)` → `stockOutSection(outOfStock)` (max 5 + tombol Lihat semua). Header title `"Stok Habis"`, count `"\(outCount) habis"`. `accessibilityIdentifier("stok-habis-section")`, `"lihat-semua-habis"`.
    *   Sentinel footer: setelah `salesCapsuleSection`, tambah `Color.clear.frame(height: 1).onAppear { guard let last = lastRefresh, Date().timeIntervalSince(last) > 2 else { return }; Task { await loadDashboard(isBackground: true) } }`.
*   **Baru: `Screens/Beranda/StockOutAllSheet.swift`:** `NavigationStack` + `List(outOfStock)` + `InlineSearchDropdownField` atau `SearchField` existing untuk filter nama/size. Tiap row tap → tidak navigasi (read-only) atau deep-link ke Produk detail jika mudah (opsional, default: tidak).
*   **Non-goals (dilarang di v3.70):** Jangan ubah kartu penjualan (tidak tambah mode bulanan), jangan ubah `MockAPIService`, jangan ubah backend.

## 6. Verification & Test Plan
*   **Smoke Test:** `xcodebuild -scheme "oura studio frontend" -destination 'platform=iOS Simulator,name=iPhone 16' build` sukses; tab Beranda tampil tanpa crash; pull-to-refresh tidak hang.
*   **Sanity Test Scenarios:**
    1. Cache instan: kill → buka app → Beranda tampil angka lama <1 frame, lalu update setelah API (cek badge timestamp berubah).
    2. Habis saja: seed 243 alerts campuran (0 vs >0) → dashboard hanya tampil qty==0, max 5 card, count header = N habis (bukan 243).
    3. Nol habis → section hilang, tidak ada ruang kosong.
    4. Pull-to-refresh memaksa API (cek `lastRefresh` update walau <60s).
    5. Pindah tab Produk → kembali Beranda <60s → tidak ada call API; >60s → background call 1x.
    6. Scroll mentok bawah 3x cepat → hanya 1 call (debounce), tidak ada loop infinite.
    7. Airplane mode dengan cache → angka lama + badge offline; tanpa cache → error state existing, tidak crash.
