# v3.34 — Penyesuaian Target Deployment ke iOS 16 & Perbaikan Kompilasi .onChange

**Status:** IMPLEMENTED
**Date:** 2026-08-26
**Changed by:** Frontend + User
**Backend changes required:** None.

---

## Latar Belakang

Aplikasi Oura Studio iOS dirancang menggunakan kerangka kerja SwiftUI standar yang kompatibel dengan SDK iOS 16 (menggunakan API native seperti `NavigationStack`, `DataScannerViewController`, dan modifier `.onChange`).

Namun, terdapat dua hambatan besar yang memblokir jalannya aplikasi pada perangkat iOS 16:
1.  **Deployment Target Salah:** File konfigurasi proyek Xcode (`project.pbxproj`) secara keliru mendefinisikan nilai `IPHONEOS_DEPLOYMENT_TARGET = 26.0`. Ini adalah nilai masa depan yang mustahil dijangkau oleh perangkat riil saat ini.
2.  **Masalah Kompilasi `.onChange` di iOS 16:** Beberapa block panggilan `.onChange` (terutama di `BahanListView.swift`) ditulis tanpa argumen penampung (misal: `.onChange(of: searchText) { displayCount = pageSize }`). Walau sintaks tanpa argumen ini didukung mulai iOS 17, di iOS 16 kompilator Swift mewajibkan adanya minimal satu argumen (nilai baru). Akibatnya, kompilasi gagal total dengan pesan error merah `'onChange(of:initial:_:)' is only available in iOS 17.0 or newer`.

v3.34 memperbaiki kedua masalah ini untuk memastikan aplikasi dapat dikompilasi secara sukses dan berjalan mulus pada seluruh perangkat iOS 16 ke atas.

---

## Solusi & Langkah Perbaikan

### 1. Penurunan IPHONEOS_DEPLOYMENT_TARGET ke `16.5`
Seluruh entri `IPHONEOS_DEPLOYMENT_TARGET = 26.0;` pada berkas `oura studio frontend.xcodeproj/project.pbxproj` (total ada 6 penempatan yang mencakup konfigurasi Debug, Release, target utama aplikasi, target Tests, serta target UITests) diubah nilainya menjadi `16.5`. Ini mengonfirmasi status kompatibilitas platform dasar secara resmi ke iOS 16.

### 2. Perbaikan Blok `.onChange` di `BahanListView.swift`
Menambahkan argument buangan `_ in` pada setiap modifikasi status `.onChange` di `BahanListView.swift` untuk mematuhi kontrak API iOS 16.

Perubahan kode:
```swift
// SEBELUM (Gagal di iOS 16)
.onChange(of: searchText) { displayCount = pageSize }
.onChange(of: selectedCategory) { displayCount = pageSize }
.onChange(of: selectedFabricFamily) { displayCount = pageSize }
.onChange(of: showArchived) { displayCount = pageSize }

// SESUDAH (Berhasil Kompilasi di iOS 16)
.onChange(of: searchText) { _ in displayCount = pageSize }
.onChange(of: selectedCategory) { _ in displayCount = pageSize }
.onChange(of: selectedFabricFamily) { _ in displayCount = pageSize }
.onChange(of: showArchived) { _ in displayCount = pageSize }
```
