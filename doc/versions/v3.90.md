# Version 3.90 - Indikator Progress Item Stok Opname (Sudah vs Belum Dicek)

## 1. Problem / Opportunity
* **Context:** Saat melakukan stok opname, user belum memiliki visibilitas mengenai berapa banyak varian produk dari total katalog toko yang sudah di-scan/dihitung, dan berapa yang belum dicek.
* **Objective:** Menambahkan indikator progress bar dan angka statistik "Sudah Dicek vs Belum Dicek" pada layar `StokOpnameScannerView` dan `StokOpnameReconcileView`.

## 2. User Flow & UX Specifications
* **Entry Point:** Sesi Stok Opname (Layar Scanner & Layar Review / Reconcile).
* **UI Components:**
  * **Progress Header / Card:** 
    * Progress bar visual (persentase selesai).
    * Statistik ringkas: `Sudah: X item • Belum: Y item • Total: Z item`.
  * **Peringatan Opsional di Reconcile:** Jika masih banyak item yang belum dicek, tampilkan *banner* info (opsional, non-blocking): *"⚠️ Masih ada 80 item katalog yang belum dihitung dalam sesi ini."*
* **Calculation Rule:**
  * `Total Katalog (Z)` = Jumlah total varian produk aktif (`ProductSize` di mana `is_archived == false`).
  * `Sudah Dicek (X)` = Jumlah item unik dalam sesi stok opname (`items.count`).
  * `Belum Dicek (Y)` = `Z - X` (minimal 0).

## 3. Frontend Implementation (SwiftUI)
* **Data Sources:**
  * Menggunakan `QRProductCache.shared.count` atau memuat total produk aktif via `api.getAllProductSizes()`.
* **Views to Update:**
  * `StokOpnameScannerView`: Tambahkan card statistik progress di atas atau di bawah area kamera.
  * `StokOpnameReconcileView`: Tambahkan baris statistik "Item Belum Dicek" pada section Ringkasan.

## 4. Verification & Test Plan
* **Smoke Test:** Verifikasi layar Scanner memuat angka statistik tanpa crash saat cache/katalog kosong.
* **Sanity Test Scenarios:**
  * Saring/scan 3 dari 10 produk → Pastikan tertulis "Sudah: 3 / Belum: 7".
  * Selesaikan opname → Periksa apakah ringkasan di layar Reconcile akurat.
