## Change 1 — `GET /products/{sku}/sizes`: response harus include semua field enrichment

### Masalah

Spec lama hanya menyebut `fabric_variant_name` di list response. iOS client menggunakan `fetchSizeToProductMap()` yang memanggil endpoint ini untuk membangun lookup `[UUID: (product, size)]` — dipakai oleh `enrichProductionBatches` untuk mengisi `latestHppBreakdown` di setiap `ProductionBatchItem`. Kalau `latest_hpp_breakdown` tidak ada di list response, RINCIAN HPP di batch confirmation selalu kosong.

### Spec Baru

```json
// Response array item untuk GET /products/{sku}/sizes
{
  "id": "uuid",
  "product_id": "uuid",
  "size_label": "M",
  "fabric_variant_name": "Satin Pelangi",   // nullable
  "reorder_min_qty": 20.0,                   // nullable
  "selling_price": 22000.0,                  // nullable
  "is_archived": false,
  "current_stock_qty": 12,
  "production_stock_qty": 12,               // Int, 0 jika belum ada produksi
  "manual_stock_qty": 0,                    // Int, 0 jika belum ada opname
  "latest_hpp_breakdown": {                  // null jika belum pernah confirmed
    "fabric": 3400.0,
    "pooled_material": 350.0,
    "hardware": 120.0,
    "labor": 2800.0,
    "overhead": 600.0,
    "total": 7270.0
  },
  "margin_pct": 0.67                         // nullable
}
```

### Field yang BARU wajib di list (sebelumnya hanya di detail endpoint)

| Field | Tipe | Keterangan |
|---|---|---|
| `latest_hpp_breakdown` | Object? | null jika size belum pernah dikonfirmasi |
| `selling_price` | Double? | nullable |
| `margin_pct` | Double? | nullable |
| `production_stock_qty` | Int | 0 jika tidak ada |
| `manual_stock_qty` | Int | 0 jika tidak ada |

## Change 2 — Tab Produksi: RINCIAN HPP data source & visibility rule

### Spec yang diperbarui

**RINCIAN HPP card** ditampilkan di expanded draft batch card, di bawah rows qty aktual.

- **Data source:** `latest_hpp_breakdown` dari `GET /products/{sku}/sizes` — diisi oleh `fetchSizeToProductMap()` enrichment di iOS, bukan dari `hpp_*` fields di batch item itu sendiri (yang masih 0 untuk draft).
- **Ditampilkan:** jika ada minimal satu batch item dengan `latest_hpp_breakdown != null`.
- **Disembunyikan:** jika semua items `latest_hpp_breakdown == null` — ini terjadi untuk produk baru yang belum pernah dikonfirmasi. Tidak memblokir konfirmasi.
- **Selection:** tap item row untuk switch ke size lain. Dot indicator (•) muncul di sebelah size label yang sedang aktif.
- **Header format:** `RINCIAN HPP · {SIZE_LABEL.uppercased()}` — e.g. "RINCIAN HPP · L"
- **Rows:** Kain (fabric), Bahan Pooled, Hardware, Tenaga Kerja, Overhead → bold HPP Total.
- **Catatan penting:** ini adalah HPP dari batch SEBELUMNYA sebagai referensi — bukan HPP yang dihitung dari batch ini. HPP batch ini baru dihitung saat `POST confirm`.
