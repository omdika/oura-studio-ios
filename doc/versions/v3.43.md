## Latar Belakang

Pada versi sebelumnya, keterangan (*caption*) pada label QR yang dicetak sering mengalami pemotongan teks (*clipping*) karena kapasitas baris yang terbatas (`maxCaptionLines = 3`), ukuran font yang terlalu besar (`5.5pt`), dan tinggi baris yang renggang (`7.0pt`). 

Selain itu, untuk produk yang memiliki varian kain dalam satu ukuran, keterangan yang ditampilkan belum memuat SKU secara lengkap di awal teks, sehingga menyulitkan identifikasi cepat saat verifikasi fisik.

v3.43 merombak format caption cetak QR agar:
1. Menampilkan seluruh informasi produk secara lengkap dalam satu kesatuan string caption:
   - Untuk produk dengan varian kain: `<SKU> - <Nama Produk> - <Size> - <Varian Kain>`
   - Untuk produk tanpa varian kain: `<SKU> - <Nama Produk> - <Size>`
2. Menghapus pencetakan label SKU terpisah tepat di bawah barcode QR untuk menghindari redundansi cetak karena SKU sekarang sudah menyatu di awal caption.
3. Menyesuaikan parameter gaya teks (styling) agar tidak terjadi pemotongan teks (*clipping*):
   - Menurunkan ukuran font caption dari `5.5pt` menjadi `4.5pt`.
   - Mengatur tinggi baris (*forced line height*) dari `7.0pt` menjadi `5.5pt`.
   - Meningkatkan kapasitas baris maksimum dari `3` menjadi `5` (`maxCaptionLines = 5`).
   - Menghitung ulang tinggi kotak caption (`captionBoxH`) menjadi `33.5pt` (`5 * 5.5 + 6`) dan total tinggi label (`labelH`) menjadi `33.5pt`.

## Perubahan Kode

### 1. `QRGeneratorView.swift` (`Self.generatePDF`)

- **Parameter Layout Baru:**
  - `captionFontSize: CGFloat = 4.5` (sebelumnya `5.5`)
  - `captionLineH: CGFloat = 5.5` (sebelumnya `7.0`)
  - `maxCaptionLines = 5` (sebelumnya `3`)
  - `skuLineH: CGFloat = 0.0` (sebelumnya `6.0`, meniadakan offset SKU terpisah)
  - `captionBoxH: CGFloat = CGFloat(maxCaptionLines) * captionLineH + 6` (= `33.5`)
  - `labelH: CGFloat = skuLineH + captionBoxH` (= `33.5`)

- **Penghapusan SKU Terpisah:**
  - Menghapus pemanggilan `size.productSku.draw(...)` yang redundan.

- **Format Label/Caption Baru:**
  ```swift
  let label: String
  if let fabric = size.fabricVariantName {
      label = "\(size.productSku) - \(size.productName) - \(size.sizeLabel) - \(fabric)"
  } else {
      label = "\(size.productSku) - \(size.productName) - \(size.sizeLabel)"
  }
  ```
