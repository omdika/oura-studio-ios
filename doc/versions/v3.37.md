**Status:** IMPLEMENTED

## Latar Belakang

Halaman **Produk** (`ProdukListView.swift`) memuat seluruh katalog produk dan seluruh ukuran/variannya sekaligus dalam satu waktu pemanggilan API tunggal. 

Ketika jumlah jenis produk bertambah hingga puluhan atau ratusan, performa rendering `ScrollView` bawaan SwiftUI mengalami penurunan drastis (*lag/frame drops*). Hal ini dikarenakan SwiftUI terpaksa mengalokasikan memori dan menggambar (*rendering*) ribuan baris elemen secara bersamaan ke dalam layar, sekalipun baris tersebut berada di area bawah yang tidak terlihat oleh mata pengguna.

v3.37 memperkenalkan **High-Performance UI Pagination (Infinite Scroll)**. Alur ini secara cerdas menggabungkan keunggulan data memori tunggal dengan pemuatan bertahap (*lazy chunking*) untuk menjamin fluiditas rendering 120Hz yang mulus tanpa mengorbankan akurasi data.

---

## Solusi & Langkah Optimasi

### 1. Lazy Chunking Sliced List
Kita mengkombinasikan total data yang telah ditarik dengan ukuran pemuatan halaman virtual (`pageSize = 20`) dan melacak jumlah item terlihat aktif (`visibleCount`):
```swift
@State private var pageSize = 20
@State private var visibleCount = 20
```

Tampilan daftar produk disaring menggunakan slice array ter-optimasi:
```swift
private var filteredProductsToDisplay: [Product] {
    Array(filtered.prefix(visibleCount))
}
```

### 2. Deteksi Infinite Scroll Trigger
Setiap kali baris kartu produk yang berada di posisi terbawah dari halaman aktif dirender di layar, sistem secara asinkron memicu peningkatan `visibleCount` sebanyak 20 item berikutnya:
```swift
.onAppear {
    if product.id == filteredProductsToDisplay.last?.id && visibleCount < filtered.count {
        visibleCount = min(visibleCount + pageSize, filtered.count)
    }
}
```

Ini memastikan siklus alokasi rendering SwiftUI berjalan secara bertahap dan instan, mengurangi beban memori grafik hingga 90%!

### 3. Keakuratan Statistika Ringkasan Atas
Karena seluruh dataset tetap ter-cache secara aman di variabel state `products` dan `allSizes`, perhitungan kartu statistika atas (Total Jenis Produk, Total Stok, dan Varian Stok Kosong) **tetap dihitung dari 100% data riil global**, menjamin kebenaran kalkulasi bisnis di mata owner Oura Studio.
