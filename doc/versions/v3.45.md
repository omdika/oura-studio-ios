# Version 3.45 - Jam Transaksi Penjualan (Transaction Time in Sales Views)

## 1. Masalah / Peluang
* **Konteks:** Pemilik toko memerlukan pelacakan transaksi penjualan secara mendetail. Saat ini, halaman daftar penjualan (`PenjualanListView`) dan detail penjualan (`EditPenjualanSheet`) hanya menampilkan tanggal transaksi tanpa menampilkan jam transaksi secara presisi (jam & menit, misal: `09:45`).
* **Objektif:** Menambahkan tampilan jam transaksi (jam & menit) pada halaman daftar penjualan (`PenjualanListView`) di baris daftar penjualan (`OrderRow`) dan halaman detail penjualan (`EditPenjualanSheet`).

## 2. Alur Pengguna & Spesifikasi UX

### A. Halaman Daftar Penjualan (`PenjualanListView` -> `OrderRow`)
1. Di setiap baris item penjualan (`OrderRow`), sistem akan menampilkan jam transaksi di sebelah informasi pembayaran dan jumlah item.
2. Format tampilan: `[Metode Pembayaran] · [Jumlah Item] · [HH:mm]` (misal: `Cash · 2 item · 09:45`).
3. Pemisah titik tengah (`·`) digunakan agar konsisten dengan gaya desain `OuraTheme`.

### B. Lembar Detail Penjualan (`EditPenjualanSheet`)
1. Di dalam section "Detail", label baris "Tanggal" akan menampilkan tanggal transaksi beserta jam transaksi secara lengkap.
2. Tampilan waktu ini menggunakan pemformatan yang ramah pengguna sesuai dengan standar SwiftUI.

---

## 3. Spesifikasi API & Perubahan Model

* Data tanggal penjualan sudah tersimpan lengkap dengan waktu (timestamp ISO8601 dengan jam, menit, detik) di properti `soldAt: Date` pada model `SalesOrder`.
* Decoder API (`APIService.swift` -> `dateDecodingStrategy`) sudah otomatis mengonversi format datetime ISO8601 dari backend menjadi objek `Date` Swift.
* Oleh karena itu, **tidak ada perubahan skema database atau API baru yang diperlukan**. Seluruh pekerjaan murni dilakukan pada lapisan visual / komponen format tanggal di frontend iOS.

---

## 4. Rincian Implementasi Kode Frontend

### A. `PenjualanListView.swift` (Komponen `OrderRow`)
* Tambahkan properti computed `formattedTime` di dalam `OrderRow`:
  ```swift
  private var formattedTime: String {
      let fmt = DateFormatter()
      fmt.locale = Locale(identifier: "id_ID")
      fmt.dateFormat = "HH:mm"
      return fmt.string(from: order.soldAt)
  }
  ```
* Tampilkan `formattedTime` setelah jumlah item:
  ```swift
  Text("· \(order.items.count) item · \(formattedTime)")
      .font(.system(size: 12))
      .foregroundStyle(OuraTheme.Colors.textTertiary)
  ```

### B. `PenjualanListView.swift` (Komponen `EditPenjualanSheet`)
* Perbarui tampilan baris "Tanggal" di section "Detail":
  ```swift
  LabeledContent("Tanggal") {
      HStack(spacing: 4) {
          Text(order.soldAt, style: .date)
          Text(order.soldAt, style: .time)
      }
  }
  ```
  * `style: .date` menampilkan tanggal yang ter-lokalisasi (misal: "30 August 2026").
  * `style: .time` menampilkan jam & menit yang ter-lokalisasi (misal: "09:45" atau "9:45 AM").
