# Version 3.57 - Perbaikan JSON Decoding Error Saat Load Resep akibat Pagination

## 1. Problem / Opportunity
*   **Context:** Setelah pembaruan ke versi `v3.56` (pagination pada `/products` dan `/product-sizes`), API `/products` mengembalikan objek paginasi `PaginatedResponse<Product>` alih-alih array datar `[Product]`.
*   **Objective:** Memperbaiki kesalahan JSON decoding (`typeMismatch expected Array<Any> at []`) yang terjadi saat memuat data resep (pattern specs) atau menyelesaikan nama produk dari SKU.

## 2. User Flow & UX Specifications
*   **Entry Point:** Sub-tab **Resep** pada tab **Produksi** (`ResepListView.swift`).
*   **UI Components:** Tampilan list resep akan menampilkan data resep pola secara lancar dan benar setelah error decoding teratasi.
*   **Validation Rules (`canSave`):** N/A (tidak ada perubahan pada input validasi).
*   **State & Progressive Disclosure:** State pemuatan pada `ResepListView` tidak lagi menampilkan status error merah ("Gagal memuat resep").

## 3. Database Schema Changes (FastAPI / SQLAlchemy)
*   Tidak ada perubahan skema database karena masalah ini sepenuhnya berada di sisi integrasi model JSON pada client-side APIService.

## 4. API Contract (FastAPI)
*   Menggunakan API Contract yang sudah ada sejak v3.56:
    *   `GET /products?page=1&limit=500` mengembalikan `PaginatedResponse<Product>`.

## 5. Frontend Changes (SwiftUI)
*   **APIService (`oura studio frontend/Networking/APIService.swift`):**
    *   Memperbarui fungsi `resolveProductName(sku:)` untuk memanggil helper `getProducts()` (yang mengambil halaman pertama dengan limit 500 dan mengekstrak `.data`) alih-alih memanggil `get(path: "/products")` secara langsung.
    *   Memperbarui fungsi `fetchSizeToProductMap()` untuk memanggil helper `getProducts()` secara langsung alih-alih `get(path: "/products")`.

## 6. Verification & Test Plan
*   **Smoke Test:**
    *   Aplikasi berhasil dikompilasi menggunakan Xcode Build.
    *   Aplikasi dapat dibuka dan dijalankan tanpa crash.
*   **Sanity Test Scenarios:**
    *   Buka tab **Produksi** -> **Resep**. Pastikan daftar resep berhasil memuat data dari live backend.
    *   Verifikasi bahwa nama produk dan ukuran tersemat dengan benar pada masing-masing resep (menandakan pemetaan SKU ke nama produk sukses).
