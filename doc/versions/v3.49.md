# Version 3.49 - Integrasi Native Google Sign-In SDK untuk iOS (Overhaul dari ASWebAuthenticationSession)

## 1. Problem / Opportunity
*   **Context:** Pada versi 3.48, otentikasi Google SSO diintegrasikan menggunakan `ASWebAuthenticationSession` (melalui kelas internal `GoogleOAuthCoordinator`). Pendekatan ini memicu kemunculan dialog konfirmasi peramban web dari iOS setiap kali masuk ("Oura Studio wants to use google.com to sign in") yang dirasa kurang mulus secara UX.
*   **Objective:** Merombak otentikasi Google SSO dengan mengintegrasikan Google Sign-In SDK resmi (`GoogleSignIn-iOS` package) secara native. Integrasi native ini menawarkan:
    1.  UX login yang lebih mulus tanpa prompt konfirmasi browser eksternal jika pengguna sudah memiliki akun Google di perangkat mereka.
    2.  Pemanfaatan modul `GIDSignIn` bawaan Google yang menangani penyegaran token dan otentikasi secara aman sesuai standar industri.
    3.  Penyaluran URL callback / redirect URL langsung dari aplikasi melalui `.onOpenURL` menuju `GIDSignIn.sharedInstance.handle(url)`.

---

## 2. User Flow & UX Specifications
*   **Entry Point:** Tombol "Masuk dengan Google" di `LoginView`.
*   **User Experience (Native SDK Flow):**
    1.  Pengguna mengetuk **"Masuk dengan Google"**.
    2.  Aplikasi memicu flow login native Google SDK (`GIDSignIn.sharedInstance.signIn(withPresenting: ...)`).
    3.  Google SDK menangani interaksi web atau otentikasi aplikasi Google lokal secara native.
    4.  Setelah otentikasi berhasil, SDK mengembalikan objek `GIDSignInResult` yang berisi `idToken` idTokenString.
    5.  Aplikasi mengekstrak `idToken` tersebut dan memanggil backend API `POST /auth/google` (disertai `invitation_token` jika ada).
    6.  Jika token valid, pengguna berhasil masuk dan diarahkan ke halaman utama.

## 3. iOS / SwiftUI Implementation Specifications

### **A. GIDClientID Konfigurasi**
Google Sign-In SDK memerlukan `GIDClientID` yang terkonfigurasi di `Info.plist` agar SDK dapat mengenali Client ID Google secara otomatis saat inisialisasi:
*   `GIDClientID`: `"763614853578-khhhap8llgs7a4obnuj2riebn5ci4t9v.apps.googleusercontent.com"`
*   `CFBundleURLTypes`: Skema URL Reversed Client ID `"com.googleusercontent.apps.763614853578-khhhap8llgs7a4obnuj2riebn5ci4t9v"`.
*   *Catatan:* Konfigurasi ini sudah siap di `Info.plist` dan `project.pbxproj` lokal.

### **B. Penyaluran URL Callback di OuraStudioApp**
Agar proses pengalihan kembali (redirect) dari Google dapat dikenali oleh Google SDK, callback URL harus disalurkan ke SDK di tingkat teratas Scene:
```swift
.onOpenURL { url in
    GIDSignIn.sharedInstance.handle(url)
}
```

### **C. Overhaul LoginView.swift**
1.  Hapus kelas pembantu kustom `GoogleOAuthCoordinator` karena fungsinya digantikan penuh oleh `GIDSignIn`.
2.  Import `GoogleSignIn` di bagian atas file `LoginView.swift`.
3.  Ubah implementasi fungsi `performGoogleLogin()` untuk memanggil API login native Google SDK:
    ```swift
    private func performGoogleLogin() async {
        errorMessage = nil
        isLoading = true
        defer { isLoading = false }

        do {
            if APIService.shared.useMock {
                try await appState.loginWithGoogle(idToken: nil, invitationToken: verifiedInvitationToken)
                return
            }
            
            // Dapatkan UIWindowScene aktif untuk presentingViewController
            guard let windowScene = UIApplication.shared.connectedScenes.first as? UIWindowScene,
                  let rootVC = windowScene.windows.first(where: { $0.isKeyWindow })?.rootViewController else {
                throw APIError.serverError(0, "Gagal mendapatkan window scene aktif")
            }
            
            let result = try await GIDSignIn.sharedInstance.signIn(withPresenting: rootVC)
            guard let idToken = result.user.idToken?.tokenString else {
                throw APIError.serverError(0, "Gagal mengekstrak ID Token dari Google")
            }
            
            try await appState.loginWithGoogle(idToken: idToken, invitationToken: verifiedInvitationToken)
        } catch {
            // Tangani pembatalan secara khusus (user cancel) agar tidak menampilkan banner error yang mengganggu
            let nsError = error as NSError
            if nsError.domain == "com.google.GIDSignIn" && nsError.code == -5 {
                // GIDSignInErrorCodeCanceled = -5 (User cancelled sign-in flow)
                return
            }
            
            if let apiError = error as? APIError {
                errorMessage = apiError.errorDescription
            } else {
                errorMessage = error.localizedDescription
            }
        }
    }
    ```

## 4. Verification & Testing Strategy
1.  **Static Compilation Check:** Memastikan seluruh proyek dapat dibangun dengan sukses (`BuildProject`) tanpa ada kesalahan sintaksis atau konflik library GoogleSignIn.
2.  **Verify Info.plist & Plist keys:** Memastikan key `GIDClientID` dan `CFBundleURLTypes` terdaftar dengan benar agar tidak terjadi crash saat runtime inisialisasi SDK.
