# Version 3.54 - Summary Penjualan (Total Omset, Total Pcs, Total Transaksi) & Flag Dibatalkan

## 1. Problem / Opportunity
*   **Context:** Layar daftar Penjualan (`PenjualanListView`) saat ini hanya menampilkan daftar transaksi beserta filter tanggal (`DateRangeField`), tanpa adanya informasi agregat/ringkasan performa penjualan dalam rentang tanggal yang dipilih.
*   **Objective:** 
    1. Menambahkan ringkasan statistik (Summary Cards) di bawah filter `DateRangeField` yang menghitung **Total Pendapatan (Omset)**, **Total Pcs Terjual**, dan **Total Transaksi (Invoice)** berdasarkan rentang tanggal aktif.
    2. Memastikan transaksi dengan status `cancelled` (dibatalkan) **TIDAK dihitung** ke dalam angka statistik agregat, namun **TETAP tampil** di daftar transaksi dengan visual badge/flag status "Dibatalkan" yang jelas dan transparan.

## 2. User Flow & UX Specifications

### Entry Point & Layout Structure
*   **Lokasi Summary Cards:** Ditampilkan secara horizontal (3 item card) di bawah `DateRangeField` dan di atas daftar transaksi (`List`).
*   **Struktur Grid Horizontal (3 Card):**
    1. **Total Pendapatan (Omset):** 
       - Icon: `banknote` / `dollarsign.circle.fill`
       - Label: "Pendapatan"
       - Nilai: Format Rupiah (contoh: `Rp 4.250.000`)
       - Perhitungan: Penjumlahan `displayRevenue` dari order berstatus bukan `cancelled` (`status != "cancelled"`).
    2. **Total Pcs Terjual:**
       - Icon: `box.truck.fill` / `bag.fill`
       - Label: "Terjual"
       - Nilai: Format angka + unit (contoh: `128 pcs`)
       - Perhitungan: Penjumlahan `qty` dari seluruh `items` di order yang bukan `cancelled`.
    3. **Total Transaksi:**
       - Icon: `doc.text.fill` / `receipt.fill`
       - Label: "Transaksi"
       - Nilai: Format jumlah (contoh: `15 trx`)
       - Perhitungan: Jumlah order berstatus bukan `cancelled`.

### Visual Flag/Badge Order Dibatalkan (`status == "cancelled"`)
*   Order yang dibatalkan tetap dirender di `OrderRow`.
*   **Badge Status Dibatalkan:** `statusTag` di `OrderRow` menampilkan tag berwarna merah/tertiary (misal: "Dibatalkan" dengan background merah pudar `red.opacity(0.12)` & font merah).
*   **Visual Muted:** Baris invoice yang dibatalkan diberi opacity sedikit lebih redup (`opacity(0.75)` atau garis strikethrough lembut pada harga) untuk memperjelas statusnya secara visual.

## 3. Database & Backend API
*   **Backend Changes:** Zero backend changes required.
*   **API Usage:** Tetap menggunakan `GET /api/v1/sales-orders?from={from}&to={to}`.
*   Model `SalesOrder` di iOS (`SalesModels.swift`) sudah memiliki properti `isCancelled`, `isPaid`, `displayRevenue`, dan `items`.

## 4. Frontend Changes (SwiftUI)

### File: `oura studio frontend/Screens/Penjualan/PenjualanListView.swift`

#### 4a. Computed Properties untuk Summary Metrics
```swift
private var validOrders: [SalesOrder] {
    orders.filter { !$0.isCancelled }
}

private var totalRevenue: Double {
    validOrders.reduce(0) { $0 + $1.displayRevenue }
}

private var totalPcsSold: Int {
    validOrders.reduce(0) { sum, order in
        sum + order.items.reduce(0) { $0 + $1.qty }
    }
}

private var totalTransactions: Int {
    validOrders.count
}
```

#### 4b. Subview: `SalesSummaryHeader`
```swift
private struct SalesSummaryHeader: View {
    let totalRevenue: Double
    let totalPcs: Int
    let totalTrx: Int

    var body: some View {
        HStack(spacing: 8) {
            SummaryTile(
                title: "Pendapatan",
                value: totalRevenue.rupiahFormatted,
                icon: "banknote.fill",
                accentColor: OuraTheme.Colors.accent
            )
            SummaryTile(
                title: "Terjual",
                value: "\(totalPcs) pcs",
                icon: "bag.fill",
                accentColor: .blue
            )
            SummaryTile(
                title: "Transaksi",
                value: "\(totalTrx) trx",
                icon: "doc.text.fill",
                accentColor: .purple
            )
        }
        .padding(.horizontal, OuraTheme.Spacing.horizontal)
        .padding(.vertical, 8)
    }
}

private struct SummaryTile: View {
    let title: String
    let value: String
    let icon: String
    let accentColor: Color

    var body: some View {
        VStack(alignment: .leading, spacing: 6) {
            HStack(spacing: 4) {
                Image(systemName: icon)
                    .font(.system(size: 11))
                    .foregroundStyle(accentColor)
                Text(title)
                    .font(.system(size: 11, weight: .medium))
                    .foregroundStyle(OuraTheme.Colors.textSecondary)
            }
            Text(value)
                .font(.system(size: 13, weight: .bold))
                .foregroundStyle(OuraTheme.Colors.textPrimary)
                .lineLimit(1)
                .minimumScaleFactor(0.8)
        }
        .padding(.vertical, 10)
        .padding(.horizontal, 10)
        .frame(maxWidth: .infinity, alignment: .leading)
        .background(OuraTheme.Colors.surfaceCard)
        .cornerRadius(10)
        .overlay(
            RoundedRectangle(cornerRadius: 10)
                .stroke(OuraTheme.Colors.separator.opacity(0.6), lineWidth: 1)
        )
    }
}
```

#### 4c. Integrasi Status Tag Dibatalkan di `OrderRow`
Memastikan `statusTag` menangani status `"cancelled"` dengan badge berwarna merah "Dibatalkan".

## 5. Verification & Test Plan

### Smoke Test
1. Buka tab **Penjualan**.
2. Pastikan 3 summary card (Pendapatan, Terjual, Transaksi) muncul tepat di bawah DateRange selector.
3. Ubah DateRange filter dan pastikan angka di summary cards diperbarui secara otomatis.

### Sanity Scenarios
1. **Transaksi Normal:** Tambahkan transaksi baru, verifikasi ketiga card bertambah nilainya.
2. **Transaksi Dibatalkan:** Batalkan transaksi atau buat transaksi berstatus cancelled.
   - Verifikasi transaksi dibatalkan **tetap muncul di list** dengan badge **"Dibatalkan"**.
   - Verifikasi total omset, pcs, dan trx di 3 summary card **TIDAK bertambah/berubah** akibat transaksi dibatalkan tersebut.
