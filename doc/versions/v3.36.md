# v3.36 — Optimasi Pemuatan Produk di Generator QR

**Status:** IMPLEMENTED
**Date:** 2026-08-26
**Changed by:** Frontend
**Backend changes required:** None (Mengoptimalkan pemanggilan API yang sudah ada).

---

## Latar Belakang

Halaman **Generator QR** (diakses dari tab Produk) sebelumnya mengalami pemuatan yang sangat lambat (*indefinite loading spinner*) ketika dibuka oleh pengguna.

### Analisis Masalah (N+1 Query Bottleneck)
Metode pemuatan data lama di `QRGeneratorView.swift` (`loadData()`) diimplementasikan secara naif menggunakan perulangan sekuensial:
1.  Melakukan kueri daftar produk (`api.getProducts()`) -> mengembalikan list produk.
2.  Melakukan perulangan sekuensial (`for product in products`) untuk setiap produk:
    *   Mengirimkan satu permintaan HTTP independen (`api.getProductSizes(sku:)`) untuk mengambil daftar ukuran/varian produk tersebut.

Jika toko memiliki 40 jenis produk, aplikasi terpaksa mengirimkan **41 HTTP request secara sekuensial** berturut-turut! Ini menghasilkan latensi total akumulatif yang sangat masif, terutama jika berjalan di koneksi mobile.

---

## Solusi & Langkah Optimasi

Kami merombak alur pemuatan data agar berjalan dengan model **Bulk Fetching (Satu Permintaan Agregat)**:
1.  Mengambil daftar produk (`api.getProducts()`) -> mengembalikan list produk.
2.  Mengirimkan tepat **satu** panggilan HTTP agregat yang mengembalikan seluruh varian produk di database sekaligus (`api.getAllProductSizes()`).
3.  Mengelompokkan data secara efisien di memori klien menggunakan operator `Dictionary(grouping:by:)` berbasis `productId` varian.

Dengan pemutakhiran ini, kueri jaringan menyusut secara dramatis dari **N+1 request menjadi hanya 2 request saja** (kecepatan pemuatan melesat puluhan kali lipat!).

## Perubahan Kode (`QRGeneratorView.swift`)

### Sebelum:
```swift
    private func loadData() async {
        isLoading = true
        defer { isLoading = false }

        let prods = (try? await api.getProducts()) ?? []
        products = prods.filter { !$0.isArchived }

        for product in products {
            let sizes = (try? await api.getProductSizes(sku: product.sku)) ?? []
            sizesByProduct[product.id] = sizes.filter { !$0.isArchived }
        }
    }
```

### Sesudah:
```swift
    private func loadData() async {
        isLoading = true
        defer { isLoading = false }

        let prods = (try? await api.getProducts()) ?? []
        products = prods.filter { !$0.isArchived }

        let allSizes = (try? await api.getAllProductSizes()) ?? []
        let activeSizes = allSizes.filter { !$0.isArchived }
        sizesByProduct = Dictionary(grouping: activeSizes, by: { $0.productId })
    }
```
