# Version 3.51 - Shopee Bulk Upload Excel Generator

## 1. Problem / Opportunity
*   **Context:** Saat ini admin Oura Studio harus memasukkan produk satu per satu secara manual ke Shopee Seller Centre untuk mulai berjualan online. Proses ini sangat memakan waktu dan rentan terhadap kesalahan input harga, stok, dan SKU.
*   **Objective:** Menyediakan fitur ekspor data produk aktif secara massal langsung dari aplikasi ke dalam format Excel (.xlsx) yang kompatibel dengan template Mass Upload Shopee. Fitur ini akan mengacu pada layout template resmi Shopee di `doc/shopee/templateShopeeBulk - Template.csv` dengan memetakan produk ke kategori **Scrunchie** (kode: `100146`) dan **Pouch** (kode: `101650`), mengosongkan kode merek, serta menyertakan berat & dimensi default otomatis berdasarkan kategori produk.

---

## 2. User Flow & UX Specifications
*   **Entry Point:** Ditambahkan tombol ekspor baru berikon kustom (`square.and.arrow.up` atau Shopee logo jika ada, default: `square.and.arrow.up`) di toolbar atas `ProdukListView`.
*   **UI Components:**
    *   **ShopeeExportSheet:** Sheet modal yang terbuka saat tombol ditekan. Menampilkan ringkasan produk siap ekspor:
        *   Jumlah produk kategori Scrunchie terdeteksi.
        *   Jumlah produk kategori Pouch terdeteksi.
        *   Informasi validasi: *"Produk tanpa kategori atau ukuran tanpa harga jual tidak akan dimasukkan ke file ekspor."*
    *   **Export Button:** Tombol utama **"Unduh Template Shopee (.xlsx)"** yang memicu request API.
    *   **Loading state:** Menampilkan spinner saat file sedang digenerate dan diunduh dari server.
    *   **Share Sheet (`UIActivityViewController`):** Setelah unduhan biner selesai, langsung pop up Share Sheet bawaan iOS sehingga pengguna bisa langsung AirDrop file `.xlsx` tersebut ke MacBook mereka, menyimpan ke Files, atau membagikannya via WhatsApp/Email.
*   **Validation Rules (`canSave`):**
    *   Hanya mengekspor varian ukuran (`product_size`) yang memiliki harga jual (`selling_price` tidak null dan > 0).
    *   Hanya produk yang memiliki kategori `'scrunchie'` atau `'pouch'` yang diekspor. Produk tanpa kategori akan diabaikan.
    *   Brand code dikosongkan secara default sesuai request.

## 4. API Contract (FastAPI)

### 4.1. Update Create/Patch Product Payload
*   **POST `/api/v1/products`**
    *   **Body:**
        ```json
        {
          "name": "Scrunchie Satin Classic",
          "sku": "SCR-001",
          "category": "scrunchie"
        }
        ```
*   **PATCH `/api/v1/products/{sku}`**
    *   **Body:**
        ```json
        {
          "name": "Scrunchie Satin Classic - Baru",
          "category": "scrunchie"
        }
        ```

### 4.2. New Endpoint: Shopee Mass Upload Export
*   **Method & Path:** `GET /api/v1/products/shopee-bulk-upload`
*   **Request Headers:** `Authorization: Bearer <JWT_TOKEN>`
*   **Query Parameters (Opsional):** None (secara default mengekspor semua produk aktif yang memiliki kategori)
*   **Backend Logic:**
    1. Ambil semua `product` aktif (tidak di-archived) yang memiliki `category` in `('scrunchie', 'pouch')`.
    2. Untuk setiap product, ambil semua ukuran (`product_size`) aktif yang memiliki `selling_price > 0`.
    3. Buat file Excel (.xlsx) menggunakan `openpyxl` atau `xlsxwriter`.
    4. Tulis 6 baris header/instruksi Shopee persis sesuai file template `doc/shopee/templateShopeeBulk - Template.csv`:
        *   **Baris 1:** Key kolom (misal: `ps_category|0|0`, `ps_product_name|1|0`, dll).
        *   **Baris 2 (KUNCI VERIFIKASI):** Token identifikasi template (`basic,007c3be4a959861bbde1d1ea24b6e962,0,63521617,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,`).
        *   **Baris 3:** Nama Indonesia (Kategori, Nama Produk, dll).
        *   **Baris 4:** Sifat kolom (Wajib, Opsional, dll).
        *   **Baris 5-6:** Penjelasan/Aturan pengisian.
    5. Mulai menulis data produk pada **Baris 7**:
        *   **Kategori Shopee (`ps_category`):** `'scrunchie'` -> `100146`, `'pouch'` -> `101650`.
        *   **Nama Produk (`ps_product_name`):** Tulis nama produk lengkap. Sesuai aturan Shopee: *hanya diisi pada variasi pertama produk*, baris variasi kedua dst dikosongkan.
        *   **Deskripsi (`ps_product_description`):** Jika kosong, buat deskripsi default informatif:
            `"Premium [Nama Produk] berkualitas tinggi persembahan dari Oura Studio. Dibuat secara higienis, jahitan sangat rapi, menggunakan bahan pilihan terbaik yang nyaman dan modis untuk pemakaian sehari-hari."` (Hanya diisi pada variasi pertama produk).
        *   **SKU Induk (`ps_sku_parent_short`):** SKU produk (hanya diisi pada variasi pertama).
        *   **Kode Integrasi Variasi (`et_title_variation_integration_no`):** Gunakan SKU induk produk (diisi di semua baris variasi).
        *   **Nama Variasi 1 (`et_title_variation_1`):** `"Ukuran"`.
        *   **Varian untuk Variasi 1 (`et_title_option_for_variation_1`):** Label ukuran/varian (misal: `"Free Size"`, `"S"`, `"M"`).
        *   **Harga (`ps_price`):** `selling_price` dari `product_size`.
        *   **Stok (`ps_stock`):** `current_stock_qty` dari `product_size`.
        *   **Kode Variasi (`ps_sku_short`):** Buat format SKU varian otomatis: `[SKU_INDUK]-[SIZE_LABEL]` (misal: `SCR-001-S`).
        *   **Merek (`ps_brand`):** Kosongkan/biarkan kosong (sesuai ketentuan).
        *   **Berat (`ps_weight`):** Default berdasarkan kategori:
            *   Scrunchie: `50` (gram)
            *   Pouch: `100` (gram)
        *   **Dimensi (`ps_length`, `ps_width`, `ps_height`):** Default berdasarkan kategori:
            *   Scrunchie: `10` x `10` x `2` (cm)
            *   Pouch: `15` x `12` x `5` (cm)
        *   **Logistik (`channel_id.8003` - Reguler Cashless):** `"Aktif"`. Jasa kirim lainnya (`channel_id.8001` dll) diisi `"Nonaktif"`.
        *   **Pre-order (`ps_product_pre_order_dts`):** Kosongkan (tidak pre-order).
    6. Mengembalikan file stream dengan response headers yang sesuai.
*   **Response (200 OK):**
    *   **Content-Type:** `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
    *   **Content-Disposition:** `attachment; filename=shopee_mass_upload.xlsx`

### 5.2. APIService Update (`APIService.swift`)
Tambahkan fungsi untuk memanggil API download Excel:
```swift
func downloadShopeeBulkUploadExcel() async throws -> URL {
    guard let url = URL(string: baseURL + "/products/shopee-bulk-upload") else {
        throw APIError.invalidURL
    }
    
    var request = URLRequest(url: url)
    request.httpMethod = "GET"
    if let token = KeychainManager.shared.getToken() {
        request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
    }
    
    let (tempLocalURL, response) = try await URLSession.shared.download(for: request)
    guard let httpResponse = response as? HTTPURLResponse, httpResponse.statusCode == 200 else {
        throw APIError.requestFailed
    }
    
    // Rename file temp agar memiliki ekstensi .xlsx yang benar
    let fileManager = FileManager.default
    let documentsURL = fileManager.urls(for: .documentDirectory, in: .userDomainMask)[0]
    let destinationURL = documentsURL.appendingPathComponent("Shopee_Mass_Upload_\(Int(Date().timeIntervalSince1970)).xlsx")
    
    if fileManager.fileExists(atPath: destinationURL.path) {
        try? fileManager.removeItem(at: destinationURL)
    }
    try fileManager.moveItem(at: tempLocalURL, to: destinationURL)
    
    return destinationURL
}
```
