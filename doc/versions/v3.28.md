## B. Diagnosis & Perbaikan Bug Peringatan Stok (Fullstack)

### 1. Analisis Bug: Mengapa Stok Kosong (0 pcs) Tidak Muncul?
*   **Backend:** Endpoint `/reports/dashboard` memanggil helper `_low_stock_alerts(db)`. Pada kode lama, kueri database menyertakan filter `.filter(ProductSize.reorder_min_qty.isnot(None))`.
*   **Edge Case:** Ketika varian ukuran baru ditambahkan (seperti pada screenshot di mana varian XS, S, M bernilai `0 pcs` dan berstatus "Belum ada harga"), field `reorder_min_qty` di database Supabase secara default bernilai `null` (`None`).
*   **Symptom:** Akibatnya, semua varian berstok kosong tersebut ter-filter keluar oleh kueri ORM dan tidak pernah masuk ke daftar peringatan dashboard.
*   **Frontend Crash Risk:** `LowStockAlert` di iOS client menggunakan properti `let id: UUID` yang wajib ada di JSON. Karena backend lama tidak mengembalikan `id` pada skema alerts-nya, jika ada alert nyata di database, decoder JSON di iOS akan mengalami kegagalan decoding (*decoding error*) dan mematikan pemuatan dashboard secara total.

### 2. Perbaikan Sisi Backend (`../backend`)
*   **Pembaruan Skema Pydantic (`app/schemas/reports.py`):**
    Ubah skema `LowStockAlert` agar `reorder_min_qty` bersifat opsional: `reorder_min_qty: float | None = None`.
*   **Optimasi & Perbaikan Kueri (`app/routers/reports.py`):**
    - Hapus filter `reorder_min_qty.isnot(None)`.
    - Gunakan `_stock_qty_map` bulk query untuk mengoptimalkan performa.
    - Logika pemicu alert:
      `is_empty = (current_stock == 0)`
      `is_low = (min_qty is not None and current_stock < min_qty)`
      Jika `is_empty` atau `is_low` terpenuhi, item dimasukkan ke daftar alert.

### 3. Perbaikan Sisi Frontend (iOS Client)
*   **Penyelarasan Model (`ReportsModels.swift`):**
    - Ubah `LowStockAlert` Swift model agar properti `id` menjadi computed property dinamis berbasis `productSizeId` (`var id: UUID { productSizeId }`). Ini menghilangkan ketergantungan `id` di JSON dan mencegah crash decoding.
    - Jadikan `reorderMinQty` opsional (`Double?`).
*   **Penyelarasan Mock (`MockAPIService.swift`):**
    - Hapus parameter `id:` pada pemanggilan inisialisasi mockup `LowStockAlert`.
