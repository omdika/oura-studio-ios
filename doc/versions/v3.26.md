## Latar Belakang

Owner ingin mengetahui apakah varian produk yang paling laris (*best-seller*) saat ini masih memiliki persediaan stok (*live stock*) yang cukup atau sedang kehabisan stok. Untuk mempermudah operasional, owner juga membutuhkan tautan instan dari halaman laporan ranking penjualan untuk langsung berpindah ke halaman detail ukuran produk tersebut, sehingga owner bisa memperbarui harga jual (Price Advisor), melihat rincian HPP, atau melakukan penambahan stok secara kilat (*fast-track replenishment*).

---

## A. Desain UI & Alur Interaktivitas (Frontend)

### 1. Penambahan Informasi Live Stok pada Baris Ranking
Pada daftar peringkat terlaris di `SalesByProductRankingView`:
- **Sebelumnya:** Hanya menampilkan total kuantitas unit terjual (misal: `12 unit terjual`).
- **Sekarang:** Ditambahkan status live stok saat ini tepat di bawah statistik penjualan dalam bentuk teks berwarna sekunder:
  - Format teks: `Stok saat ini: X pcs`
  - Jika stok habis ($X = 0$), teks status menggunakan warna bahaya `OuraTheme.Colors.dangerText` ("Habis") untuk menarik perhatian owner.

### 2. Tautan Navigasi Instan ke `ProdukSizeDetailView`
- Setiap baris peringkat diubah menjadi `NavigationLink` atau tombol interaktif yang meluncurkan `ProdukSizeDetailView(productSize: sizeDetail)`.
- Untuk membuka halaman detail ini, program harus melakukan langkah pencarian data atau memuat objek `ProductSizeDetail` berdasarkan `productSizeId` dari item ranking terpilih melalui API `api.getProductSizeById(id:)`.
- Selama memuat data detail untuk beralih layar, indikator loading mini ditampilkan untuk transisi yang mulus.

### 2. Penambahan Kueri Live Stok di Endpoint Router (`app/routers/reports.py`)
Modifikasi kueri `/reports/sales-by-product` untuk menghitung sisa stok fisik saat ini dengan membaca `StockLedger` menggunakan helper `_stock_qty_map` (sebagaimana pola yang ada di router products):

```python
    # ... kueri ranking teragregasi yang sudah ada ...
    
    size_ids = [r.product_size_id for r in results]
    from app.routers.products import _stock_qty_map
    stock_map = _stock_qty_map(db, size_ids)

    return [
        ProductSalesRankingEntry(
            product_size_id=r.product_size_id,
            product_name=r.product_name,
            size_label=r.size_label,
            fabric_variant_name=r.fabric_variant_name,
            qty_sold=int(r.qty_sold),
            revenue=float(r.revenue),
            profit=float(r.profit),
            current_stock_qty=stock_map.get(r.product_size_id, 0), # NEW
        )
        for r in results
    ]
```
